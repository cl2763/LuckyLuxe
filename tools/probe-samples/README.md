# 判据物的家(J-61④)

靶子 / 夹具 / 造病物 / probe 样本**只住这里**。

**为什么要有这个目录**:全仓那几十把扫描刀认的是**句柄**不是文件名 —— 靶子写在哪、哪就被数。
本会话两次踩过:probe 靶子里的字面量 SQL 被「夹具直连库贴」那把刀数进欠账;白名单的理由文字
被「真环境只许判一处」数成第二处出口,**逼着去改一段本来正确的文字**(裁 #88 同族)。

**规矩**
1. 新加判据靶子,写进 `index.mjs`,不写在判据文件里。
2. 走全仓的刀**按这个目录名排除**(具名,不许按模式放行)。
3. 排除必须配**两面断言**:①样本在这个目录里不许被数 ②同一样本在普通路径里必须被数。
   **缺第二面,这个排除就是给判据挖的一个没人看得见的洞。**
