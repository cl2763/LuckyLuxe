# 小批 12k —— 从第七轮起,对比包一律做成「可点反馈」的本地 HTML:每格 过 / 不过 / 有问题 + 备注,一键导出反馈文件

店主 09-24 原话:再出对比包,要能在页面里直接点「过 / 不过 / 有什么问题」,反馈更精准。
这条同时就是 12i 补 §一-3「店主偏好数据集」的采集口 —— 她每点一次都是一条带标签的数据。¥0,`apps/` 不动(这是产出夹里的静态页,不是产品页)。

## §一 形状(定死)
- 仍是**本地单文件 HTML**(顾客照片不出她的机器;不上 claude.ai 不上任何网页)。
- 每一格(每张图)下方三个按钮:**过 / 不过 / 有问题**,选「有问题」展开一个文本框;每一**行**(同一张原图的所有版本)末尾一个「这行我最喜欢哪版」下拉。
- 点选即写入浏览器本地存储(刷新不丢);页顶一颗「**导出反馈**」按钮,生成 `反馈_对比包_第N轮_YYYY-MM-DD.json`(浏览器下载)+ 同内容的 `.md` 人话版(一行一条:行号 / 版本名 / 过·不过·有问题 / 备注 / 这行最喜欢)。她把文件放回产出夹 `_反馈/` 即可。
- 页顶显示「已填 x / 共 y 格」,没填完导出时提示但不拦。
- 每格的标题就是 12e §六 的人话名(`44_模型只去瑕疵+亮度回贴全+皮肤层冷白轻+磨皮`),反馈文件里带同一名字 —— 这样她说「哪版」和文件对得上。
- 键盘:1=过 2=不过 3=有问题,方向键换格(可选,做不做 Code 定,做了要写在页顶)。

## §二 Code 侧
1. 写 `tools/ai-retouch-eval/feedback-widget.js`(单文件,内联进对比包,不引外链),现有 `build-report*.mjs` 出页时统一嵌入;**第五轮对比包也回炉嵌一次**(她已看过,可能想回头点)。
2. 写 `ingest-feedback.mjs`:读 `_反馈/*.json` → 追加到 `tools/ai-retouch-eval/偏好数据集.jsonl`(字段:日期、轮次、序号、版本名、处理链、判定、备注、行最喜欢、当时的四数)。**这个 jsonl 就是 12i 补 §一-3 那份数据集**,只追加不改写。
3. 判据:①导出的 json 条数 = 页面已填格数(页内自检);②`ingest` 后 jsonl 行数增量 = json 条数;③页面在 Safari 与 Chrome 都能点、都能导出(她用哪个我不知道,两个都验,截图);④落一刀:改坏本地存储键名 → 刷新后丢失 → 红。
4. 回执附:一张她能照着点的 30 秒说明(页顶也放同一段)。
