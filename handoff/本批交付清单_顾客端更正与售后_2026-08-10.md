## corner case(六类制度)

| 类别 | 用例 |
|---|---|
| 边界值 | 差额 0 / 负到应付归零 / 多笔一正一负相抵 |
| 空态 | 无更正的普通单整块不渲染;无售后单空态无金额行 |
| 幂等 | 同一单反复打开,实际应付不变 |
| 异常输入 | 原因超长 / 原因含特殊字符(原文显示不越界) |
| 越权 | 顾客只能看自己那张单 |
| 财务红线 | **实际应付 ≡ 原单合计 + Σ差额**;更正不改原单一个字节 |
