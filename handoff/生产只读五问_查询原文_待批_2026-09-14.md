## 五条语句(逐条原文,全部 `SELECT` 开头)

### 问 1 · 同号多条:每家店有多少个手机号对应多于一条档案,涉及多少顾客

```sql
SELECT u.tenant_id,
       COUNT(*)              AS 同号多条的号码数,
       SUM(u.c)              AS 涉及顾客数
FROM (
  SELECT tenant_id, TRIM(phone) AS p, COUNT(*) AS c
  FROM users
  WHERE phone IS NOT NULL AND TRIM(phone) <> ''
  GROUP BY tenant_id, TRIM(phone)
  HAVING COUNT(*) > 1
) u
GROUP BY u.tenant_id
ORDER BY 同号多条的号码数 DESC;
```

### 问 2 · 没有手机号:每家店多少个,并分开「导入的」与「非导入的」

```sql
SELECT tenant_id,
       COUNT(*)                                                          AS 顾客总数,
       SUM(CASE WHEN phone IS NULL OR TRIM(phone) = '' THEN 1 ELSE 0 END) AS 没有手机号,
       SUM(CASE WHEN (phone IS NULL OR TRIM(phone) = '') AND is_migrated = 1 THEN 1 ELSE 0 END) AS 没号且是导入的,
       SUM(CASE WHEN (phone IS NULL OR TRIM(phone) = '') AND is_migrated <> 1 THEN 1 ELSE 0 END) AS 没号且非导入,
       SUM(CASE WHEN wechat_open_id IS NOT NULL AND wechat_open_id <> '' THEN 1 ELSE 0 END)      AS 已绑微信
FROM users
GROUP BY tenant_id
ORDER BY 没有手机号 DESC;
```

### 问 4 · 🔴 **有储值余额**的顾客里,问 1 / 问 2 各占多少

> 余额 = 该顾客所有 `stored_value_transactions.amount_cents` 之和 > 0
> (仓里算余额就是按这张表求和;`bucket` 只分「老系统迁来的 legacy」与「本店 normal」,两者都算她的钱)

```sql
SELECT b.tenant_id,
       COUNT(*)                                                           AS 有余额的顾客数,
       SUM(CASE WHEN b.同号 > 1 THEN 1 ELSE 0 END)                        AS 其中_同号多条,
       SUM(CASE WHEN b.phone IS NULL OR TRIM(b.phone) = '' THEN 1 ELSE 0 END) AS 其中_没有手机号,
       SUM(b.余额分)                                                      AS 这批人的余额合计分
FROM (
  SELECT u.id, u.tenant_id, u.phone,
         (SELECT COALESCE(SUM(s.amount_cents), 0) FROM stored_value_transactions s
           WHERE s.user_id = u.id AND s.tenant_id = u.tenant_id) AS 余额分,
         (SELECT COUNT(*) FROM users u2
           WHERE u2.tenant_id = u.tenant_id AND TRIM(u2.phone) = TRIM(u.phone)
             AND u.phone IS NOT NULL AND TRIM(u.phone) <> '')     AS 同号
  FROM users u
) b
WHERE b.余额分 > 0
GROUP BY b.tenant_id
ORDER BY 有余额的顾客数 DESC;
```

### 问 5 · 🔴 **有卡包 / 有积分**的顾客里,问 1 / 问 2 各占多少

```sql
SELECT b.tenant_id,
       SUM(CASE WHEN b.券数 > 0 THEN 1 ELSE 0 END)                                      AS 有卡包的顾客数,
       SUM(CASE WHEN b.券数 > 0 AND b.同号 > 1 THEN 1 ELSE 0 END)                        AS 卡包_同号多条,
       SUM(CASE WHEN b.券数 > 0 AND (b.phone IS NULL OR TRIM(b.phone) = '') THEN 1 ELSE 0 END) AS 卡包_没有手机号,
       SUM(CASE WHEN b.积分数 > 0 THEN 1 ELSE 0 END)                                     AS 有积分的顾客数,
       SUM(CASE WHEN b.积分数 > 0 AND b.同号 > 1 THEN 1 ELSE 0 END)                       AS 积分_同号多条,
       SUM(CASE WHEN b.积分数 > 0 AND (b.phone IS NULL OR TRIM(b.phone) = '') THEN 1 ELSE 0 END) AS 积分_没有手机号
FROM (
  SELECT u.id, u.tenant_id, u.phone,
         (SELECT COUNT(*) FROM coupon_grants g
           WHERE g.user_id = u.id AND g.tenant_id = u.tenant_id AND g.status = 'active') AS 券数,
         (SELECT COALESCE(SUM(p.amount), 0) FROM points_transactions p
           WHERE p.user_id = u.id AND p.tenant_id = u.tenant_id)                         AS 积分数,
         (SELECT COUNT(*) FROM users u2
           WHERE u2.tenant_id = u.tenant_id AND TRIM(u2.phone) = TRIM(u.phone)
             AND u.phone IS NOT NULL AND TRIM(u.phone) <> '')                            AS 同号
  FROM users u
) b
GROUP BY b.tenant_id
ORDER BY 有卡包的顾客数 DESC;
```
