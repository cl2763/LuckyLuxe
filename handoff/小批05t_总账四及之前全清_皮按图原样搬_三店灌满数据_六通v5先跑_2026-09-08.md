**裁 —— 令牌与字体从图里「原样搬」,不是参考、不是取色:**

1. **新件 `apps/web/design-tokens.css`**:把图 HTML 里那三段 `:root{...}`(light / `@media prefers-color-scheme:dark` 内的 `:root:not([data-theme="light"])` / `:root[data-theme="dark"]`)**逐字符搬过来**,一个变量不增不减不改值;`styles.css` 与 `admin.html` 引它;dh- 块里所有 `var(--x, #硬编码)` 的兜底值**删掉**(取不到就该露出来,不许悄悄退成另一套色)。
2. **刀:`tools/design-token-diff.mjs`** —— 从合同图 HTML 现抽 `:root` 三段,与 `design-tokens.css` 逐条比对**名与值全等**,多一个少一个或值差一位都红;进预检。**这把刀是「图=合同」的机械化**:以后图改了、皮没跟上,当场红。
3. **字体**:网页端加载 Fraunces + Noto Serif SC + Noto Sans SC。**先报方案再落地**(写进回执,不要自己发挥):① 直接用图里那行 Google Fonts `<link>`(最省事,但生产在墙内可能慢);② 自托管 woff2 放 `apps/web/fonts/`(推荐,顺带进上线批)。**今天先按 ① 落地保证看得见,同时把 ② 写进上线批清单。** 判据:`getComputedStyle` 取大数字元素 `font-family` 第一项 === `Fraunces`;标题 === `Noto Serif SC`。
4. **深色英雄块**:`[data-dh-hero]` 背景 = `--hero`,大数字 = `--herogold`,内部细网格 `--herogrid`;左栏此刻四格、下一位卡都在这块深色里(图 §三);右四小牌仍是浅色卡。判据:`getComputedStyle([data-dh-hero]).backgroundColor` 转 hex === `--hero` 当前值(light/dark 各测一次)。
5. **折线**:补 `<defs><linearGradient>` 与末点 `circle`,`stop-opacity` .35 → 0,描边 `--herogold`。判据:`svg[data-dh-spark] linearGradient stop` 两个 + `circle` 一个;造病:去掉 defs → 红。
6. **数字滚动**:大数与四小牌切维度时 `requestAnimationFrame` 从旧值滚到新值 **600ms**;`@media (prefers-reduced-motion: reduce)` 直接跳。判据:DevTools 里切维度后 200ms 采样,值既 ≠ 旧也 ≠ 新(在滚);打开 reduce 后同样采样只见新值;造病:去掉动画 → 第一条红。
7. **深浅两态都要对**:`[data-theme=dark]` 与系统深色各截一张。

**不许**:自己调色、自己配近似字体、把令牌"简化"成几个。**图上有的值,一个都不许改**;图上没写的(比如某个 hover),按同族令牌推,并在回执里列出来我核。
