| # | 字段/动作 | 前端拦 | 后端原来拦吗 | 结果 |

**三个真缺口,长这样:**
- **A3**:后端 `Math.max(0, ...)` 把 0 和负数一律吞成 0 就照建 → 建出一张**减 0 元的券**。
  发出去顾客点了没反应,店里还以为发过了。
- **A4**:同样的吞法 → **卖 0 元的储值套餐**、**含 0 次的次卡**。顾客买了等于白买,而账面上确实"卖出去一份"。
- **A5**:`Number(...)` 照收 → **负价项目**建得出来。项目价是报价、结算、业绩的基数,
  一处负数一路负下去(小计、分成、积分);`Number('abc')` 变 NaN 更难查。
  **三条写路**(建项目 / PATCH 改项目 / 价目页改价)现在过同一把闸。

新套件 `test-backend-gate.mjs`,**15 项断言**;闸的实现搬进新模块 `write-gates.mjs`
