
**就是跟 `api` 那条一模一样,只把 `api` 换成 `app`。**
加完等一两分钟,你可以在浏览器里打开 `http://app.jingshengyouji.com`(先是 404 或连不上,正常 —— 证书还没签)。

## 二、要你做的第二件:平台控制台的账号(11p §二 乙支)

我把「用密码登录平台控制台」这条路做出来了。**口令必须你自己生成、你自己灌** ——
代码不生成、不打印、不拷贝,我和 Cowork 都看不到。

### 顺序(等这一批推上去、Railway 重启完之后)

1. **自己生成一串**(≥16 位随机)。比如在你自己的终端里跑:

```bash
node -e "console.log(require('crypto').randomBytes(18).toString('base64url'))"
```

2. Railway → 项目 → Variables,加两条:

```
PLATFORM_ADMIN_BOOTSTRAP=1
PLATFORM_ADMIN_INITIAL_PASSWORD=<上一步那串>
```

3. 等它自动重启 → 打开 `/platform` → 用户名 **`platform-admin`** + 那串 → **首登会强制你改密**,改成你自己记得住的。

4. 改完把 `PLATFORM_ADMIN_INITIAL_PASSWORD` **从 Railway 删掉**(留着不危险,但没必要留)。

5. 新密码**自己记进本机凭据文件**,🔴 **不要发给我,也不要发给 Cowork。**

### 以后再忘了怎么办

同一条路,换两个变量:

```
PLATFORM_ADMIN_RESET=1
PLATFORM_ADMIN_INITIAL_PASSWORD=<新的一串>
```

重启后它会重写密码、要你首登改密、**并把之前登着的设备全部踢掉**。
用完把 `PLATFORM_ADMIN_RESET` 删掉 —— **不删也不会出事**(同一串口令第二次重启不会再生效,
否则你改过的新密码每次重启都会被打回去),但删掉更干净。

### 🔴 一句要说清的

**生产上原来根本没有这个账号** —— 不是你找不到密码,是它从来没被建出来过(生产库 `platform_accounts` 现在是 0 行)。
2026-09-19 那次为了不让一次性口令进 Railway 部署日志(那种日志事后删不掉),把自动建号关掉了,
留了「甲:不用这个账号 / 乙:用,但口令你自己灌」两条路等你选。**你今天这句话就是选了乙。**

## 三、这一批顺带改的一件:链接域名按店走

以前所有店的**推荐链接 / 签署链接 / 绑定链接**都写死用 `www.luckyluxeatelier.com`。
小婕的顾客在境内点那条链接会很慢甚至打不开,**而系统不会报任何错**。

现在按店走:

| 店 | 链接用哪个域 |
|---|---|
| 币种 CNY 的店(小婕 / 北京旗舰店) | `https://app.jingshengyouji.com` |
| 其余(多伦多) | `https://www.luckyluxeatelier.com` |

**建店表单里多了一个「对外域名」下拉** —— 留空就按币种自动定,要例外才手动选。
判据已经钉住:建一家 CNY 店和一家 CAD 店,各取一条真链接比域名。

⚠️ **这条要等第一件(DNS + 证书)做完才真正可用** —— 在那之前 CNY 店拿到的链接指向一个还没通的域名。
所以顺序是:**你加 DNS → 我签证书实访 → 再推这一批上生产。**
