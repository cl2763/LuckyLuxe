# 体验版验图清单(店主 · 2026-08-23)

体验版这次连的是**生产**(不是沙箱)。图能不能显示看两件事:
①小程序里的图标——已由 SVG 全部换成 PNG(**本次代码里就带着**,一定生效);
②签署单快照/笔迹——由**服务器**出图,需要生产端装上栅格化组件(本次一并发上去,验法见下)。

## 看这几处(顺手点一遍,哪处白了拍给我)

1. **商家端底部导航**:首页 / 订单 / 工作台 / 图库 / 管理 —— 5 个小图标要有图形,不是空白。
2. **顾客端「我的」页**:消息 / 储值 / 优惠券 / 门店 / 会员 / 礼品 六个圆形菜单图标。
3. **商家端「管理」页九宫格**:排班 / 财务 / 客户 / 营销 / 员工 / 门店…每格左上角图标。
4. **商家登录页**:密码框右边的「眼睛」图标(点一下能切换明文)。
5. **顾客端订单详情 → 查看原件**:浮层里应出现整张服务确认单(中文、金额、签名框清晰),
   多份组能左右滑动/点两侧箭头翻页,页码显示 n/N。
6. **商家端日结 → 查看签署单**:同一个浮层,多份组同样能翻页。
7. **长按存图**:在浮层图片上长按 → 应弹出「保存图片」。

> 5–7 需要生产上有**已签署**的单。生产目前 0 张签署单:要么在体验版里开一单签一张(会写真实数据),
> 要么这三项留到有真实单据时再看——您定。

## 判断服务器出图有没有到位(我这边也会盯)

打开 https://www.luckyluxeatelier.com/health,看 `snapshotRaster` 字段:
- `rsvg-convert` = 生产已能出 PNG,快照图正常;
- `none` = 还没装上(快照会回落 SVG,真机上仍是白图)——这时告诉我,我继续修。
