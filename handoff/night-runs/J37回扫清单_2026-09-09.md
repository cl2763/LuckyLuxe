# J-37 回扫清单 —— 「在不在」不等于「看得见」(店主 05w §五 立,裁 #24)

> **律**:凡「必须让人看见」的元素,判据要量它**落没落在可见区里**
> (包围盒 ⊂ 容器可见区、没被 `overflow` 剪掉、没被别的层压住、宽高 > 0),
> **不许只问它存不存在 / `hidden` 是不是 false**。
> 归族判据律那句:**在缺陷存在时照样绿的判据就是废判据。**

## 回扫方法(白名单式,不是列举)

把**所有会取 DOM/节点的判据文件**抠出来,逐个回答两问:①它断言的是不是「人得看见」?
②它有没有几何量(`getBoundingClientRect` / `offset()` / `size()` / 可见区比较)?
机械口径:

```bash
for f in tools/*.mjs apps/api/test-mp-*.mjs apps/api/test-dashboard-home.mjs apps/api/test-today-board.mjs apps/api/test-ui-spec.mjs; do
  exist=$(grep -cE "querySelector|\$\(|\$\$\(|getElementById" "$f")
  geo=$(grep -cE "getBoundingClientRect|offset\(\)|\.size\(\)|clientWidth|scrollWidth|可见区|包围盒" "$f")
  [ "$exist" -gt 0 ] && echo "$f 取元素 $exist · 几何 $geo"
done
```

## 本批补的两处,现测

- `store-name-switch-proof ①v`:新判据在**两家店各跑一次**;
- `mp-theme-proof`:`bgOf()` 现在会因「宽高为 0」直接给出不可见的说明串,颜色判据随之红。

## 还欠一句(如实写)

「没被别的层压住」我用的是 `elementFromPoint(中心点)`。**它只探中心一个点** ——
一个只被压住半边的元素照样能过。要更严就得取四角 + 中心五点,或者按覆盖面积算。
本批先立中心点这一档(比原来的「存不存在」严得多),**要不要升到五点,登记待店主裁**。
