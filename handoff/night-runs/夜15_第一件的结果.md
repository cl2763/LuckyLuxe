# 夜15 §一 · 「拉不起来」那一句 —— 十分钟内的结论

## 结论:**搜不到 ⇒ 沙箱在 CI 上起来了,起来的是空库 ⇒ 按 §二 做 (丙)**

## 🔴 但这个「搜不到」的扫描面必须写清(J-65③)

**我能拿到的只有 CI 的注解,而注解里只有「红行 + 末 25 行」,不是全日志。**
`/actions/jobs/<id>/logs` 匿名取是 **403(要 admin)**。
**⇒ 这个 0 只能说「那一段里没有」,不能说「全日志里没有」。**

## 但有一条**量出来**的间接证据,它比字符串搜索更硬

```
apps/api/test-demo-mark.mjs:106        if (!sb.ok) { …跳过… } else { …行为层… }
CI 注解里那条红:  not ok 9 - ⑤ … :: {"marked":{"bookings":0,"settlements":0},"tags":[]}
```

**⑤ 在 `else` 分支里。它跑到了 ⇒ `sb.ok` 为真 ⇒ `ensureSandbox()` 成功了 ⇒ 沙箱服务起来了。**
同理 `tenant-ownership ③c` 也在 `else` 里,上一次 CI 它也跑到了。

**⇒ 两套判据各自从 `else` 分支里发出声音,而那个分支只有沙箱起来才进得去。**
**这比搜一个字符串更硬:它不是「没看见反例」,是「看见了正例」。**

## 机理也对得上

```
apps/api/test-need-sandbox.mjs:68
  spawn('bash', ['start-sandbox.sh', 'sandbox-data'], { cwd: process.cwd(), … })
```
CI 上 `apps/api/sandbox-data/` **不存在**(`.gitignore:26`)⇒ 服务自己建一个 ⇒ **空库**。
**缺的是夹具数据,不是沙箱服务。09y §一 成立。**

## 顺手补一件(下一次 CI 就能literal 回答这一问)

已在 `ci.yml` 的失败分支里加一行:把 `grep -c '拉不起来' ci.log` 的数打进注解。
**⇒ 下一次 CI 红时,这一问有字面答案,不用再靠间接证据。**
