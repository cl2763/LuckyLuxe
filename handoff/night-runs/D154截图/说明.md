## D156 · 顶栏显当前店名(补二第三条)

**取哪一个名字,是这条的关键**:店主写的是 `stores.name`,不是 `tenants.name` —— 这两个**真的会分叉**:

- 商家在门店设置改店名,走 `PUT /admin/store-info`,改的**只有** `stores.name`;
- `tenants.name` 从建店起就没人再动过。

**本机库现测的活证据**(不是推理):

```
租户 demo-ai:
  tenantName = 星野美甲(演示·AI版)      ← 小程序商家端两处以前显示的就是这个(旧名)
  storeName  = 星野美甲 · 演示店          ← 商家自己在门店设置里看到、改到的那个
```

所以谁显示 `tenantName`,谁显示的就是**改名之前那个名字**。口径定死:
**`tenantName` = 商户名(平台侧看的)· `storeName` = 门店名(商家自己看的)**。

**双端同批**:小程序商家端两处(`pages/merchant/manage`、`pages/merchant/me`)同批改成读 `storeName`;
`me` 那处顺手拆掉 `|| displayName || '我的店铺'` 的回落链 —— 取不到店名就把**人名**顶上来、
甚至编一个「我的店铺」,那是零回落红线明令禁止的。

**三张图的探针**(页面上写的 ≡ 接口给的):

```
07 旗舰  顶栏「LUVIA 半径」            ≡ storeName「LUVIA 半径」
08 小婕  顶栏「小婕的店(沙箱)」        ≡ storeName「小婕的店(沙箱)」
09 北京  顶栏「LUVIA 半径美甲美睫 · 北京旗舰店」≡ storeName 同上
```

先登 A 再登 B,五条 —— ①A 的名字对 ②**点「退出」之后那一行不再是 A**(不重载页面;
