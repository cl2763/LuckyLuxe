## 二 §五.2 · 改形状:不只数行数,**逐行列出**

两家真店量级小,**数分不开,人眼分得开**。

### 查询 ① · 底数与三格闭合(先证明这张表在生产上是什么样)

```sql
SELECT
  COUNT(*)                                                              AS mock_total,
  SUM(CASE WHEN transaction_id LIKE 'mock%'    THEN 1 ELSE 0 END)        AS confirmed_by_endpoint,
  SUM(CASE WHEN transaction_id IS NULL         THEN 1 ELSE 0 END)        AS born_paid,
  SUM(CASE WHEN transaction_id IS NOT NULL
            AND transaction_id NOT LIKE 'mock%' THEN 1 ELSE 0 END)       AS other
FROM payments
WHERE provider = 'MOCK';
```
**判据**:后三格相加必须等于 `mock_total`,加不上先查指纹(J-58⑨ / J-66)。

### 查询 ② · 按店分组(看这件事落在谁身上)

```sql
SELECT tenant_id, COUNT(*) AS n, MIN(created_at) AS first_at, MAX(updated_at) AS last_at
FROM payments
WHERE provider = 'MOCK' AND transaction_id LIKE 'mock%'
GROUP BY tenant_id ORDER BY n DESC;
```

### 查询 ③ · 🔴 单向指纹:**不可能走有门那条**的那些

```sql
SELECT p.tenant_id, p.booking_id, p.amount_cents, p.created_at, b.status AS booking_status
FROM payments p
JOIN bookings b ON b.id = p.booking_id
LEFT JOIN users u ON u.id = b.user_id
WHERE p.provider = 'MOCK'
  AND p.transaction_id LIKE 'mock%'
  AND (u.wechat_open_id IS NULL OR u.wechat_open_id = '')
  AND (SELECT COUNT(*) FROM user_identities ui
        WHERE ui.user_id = u.id AND ui.provider IN ('wechat_miniprogram','google')) = 0
ORDER BY p.tenant_id, p.created_at;
```
**这是下限,不是总数** —— 读的时候别把它当「被打了这么多次」。

### 查询 ④ · 逐行全列(§五.2 要的那一张)

```sql
SELECT p.tenant_id, p.booking_id, p.amount_cents, p.transaction_id,
       p.created_at, p.updated_at,
       b.status AS booking_status, b.source_channel, b.demo_seed,
       u.display_name, u.wechat_open_id IS NOT NULL AS has_wechat
FROM payments p
JOIN bookings b ON b.id = p.booking_id
LEFT JOIN users u ON u.id = b.user_id
WHERE p.provider = 'MOCK' AND p.transaction_id LIKE 'mock%'
ORDER BY p.tenant_id, p.created_at;
```
