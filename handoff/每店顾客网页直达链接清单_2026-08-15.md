# 每店顾客网页直达链接清单(D45 · 2026-08-15)

> **寻址方式**:同一个域名,`?store=<租户ID>` 参数进店(「每店专属链接」模型——商家把自己店的链接发给顾客,店内不切店)。
> 打开一次后浏览器会**记住这家店**(localStorage):之后直接访问裸域名也停留在这家店,换店就点另一条链接。
> 此前顾客网页**没有任何按店寻址**(店 id 写死旗舰店,任何人访问都只能看到 lucky)——本批立 D45 修出,CI ㉝ 常驻两条断言。

# 附:devtools 整只重启操作卡(小程序看不到「起」时先做这个)

1. **彻底退出微信开发者工具**:菜单栏「微信开发者工具 → 退出」(⌘Q)。点右上角红叉或只点「编译」都**不够**——编译缓存会带着旧 wxml(卫生批实锤过的机制)。
2. 确认本地服务器活着:浏览器开 http://127.0.0.1:4128/health ,看到 `"ok":true` 才继续;打不开就双击「启动服务器.command」。
3. 重新打开微信开发者工具 → 打开本项目 → 等它自动编译完。
4. 顾客端切到 Lucky Luxe(或 Jie's Nail)→ 底部「服务」Tab → 每张服务卡价格应显示「CAD $xxx 起」(jics 店则为 ¥xxx 起)。
5. **重启后仍无「起」**:在 devtools 的 Network 面板点一条 `/services` 请求 → 看返回 JSON 里有没有 `priceFromLabelZh` 字段,把这一条的截图发回来——有字段=渲染层问题,没字段=请求打错了环境,一张图就能定位。

> 手机上的正式/体验版小程序是**旧代码包**,要等下次发版才有「起」(已入发版清单),不用在手机上验这条。
