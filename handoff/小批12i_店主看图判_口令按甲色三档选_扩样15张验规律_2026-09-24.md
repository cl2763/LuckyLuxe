## §二 甲色三档怎么定(机器判,不许人眼判,否则产品做不了)
甲面区仍用「手 bbox 内非肤色连通块」粗估(已知红甲/裸甲会被当皮肤 → 这两类粗估会失败,**失败就默认 A**,并在日志记「甲面区取不到」)。对甲面区量两数:Y 均值(明暗)、色度半径 C = sqrt((Cb−128)² + (Cr−128)²)(鲜明度)。
- **浅**:Y ≥ 90 → A
- **深·鲜明**:Y < 90 且 C ≥ 25 → A(红、黑紫这类)⚠️ 纯黑 C 很小,会落进「深·不鲜明」—— 与她说的「黑要 A」冲突;**先按数跑,黑甲的结果单独标出来给她看**,门槛由她的眼睛定,不许拟合。
- **深·不鲜明**:Y < 90 且 C < 25 → A′
门槛 90 / 25 是起手值,跑完按 15 张分布给她看,**不许自己调了再跑**。
