## 三 · 落到已有库怎么办(这一条决定改名会不会「只对新库生效」)

`local-server.mjs` 里那四处是 `INSERT OR IGNORE` —— **只对全新库生效**。
本机库、沙箱库、**生产库**里的行早就存在,不改种子就不会变。所以必须配一条**迁移**:

```sql
UPDATE tenants        SET name = ? WHERE id = 'lucky-luxe';
UPDATE stores         SET name = ? WHERE tenant_id = 'lucky-luxe';
UPDATE tenant_kb_facts SET value = ? WHERE tenant_id = 'lucky-luxe' AND key IN ('brandName','assistantName');
```
**三条全部带 `tenant_id='lucky-luxe'` 限定** —— 这正是您红线三防的事(不许改成全局默认值)。

- **本机库 / 沙箱库**:我可以直接跑。
- **🔴 生产库**:按纪律**写生产要单独批准**。我这批**不碰生产**,只把迁移写好、在本机与沙箱验完,
  生产那一步单独报您批。
