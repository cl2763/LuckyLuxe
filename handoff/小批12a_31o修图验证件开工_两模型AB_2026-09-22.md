## 1. 做什么
在 `tools/ai-retouch-eval/` 下写一个独立脚本（Node 或 Python 均可，与主线零依赖），对每张样片 × 每条预设 × 两个模型各出一张图，产出对比包。

### 1.1 模型（A/B）
| 代号 | Model ID | 说明 |
|---|---|---|
| A | `doubao-seedream-4-5-251128` | 主力候选 |
| B | `doubao-seedream-5-0-pro-260628` | 对照 |
| （C） | flash，ID 在方舟卡片上 | **本批不跑**；A/B 定了赢家后再用赢家的口令跑 3 张看质量差多少 |

接口：`POST https://ark.cn-beijing.volces.com/api/v3/images/generations`，`Authorization: Bearer $ARK_API_KEY`。
请求体最小集：`{"model", "prompt", "image": <公网 URL 或 base64，按方舟文档二选一>, "size": "2K", "watermark": false, "response_format": "url"}`。
**`watermark` 必须 false**（控制台示例默认 true）。样片先传 COS 拿直链，复用现有 COS 桶与白名单；如果方舟支持 base64 输入就不用传 COS，以文档为准。

### 1.2 预设（6 条，按 09-20 分析件改进版口令 A 的结构）
每条 prompt = **固定前缀（绝对不改清单）** + 本预设段 + 固定后缀。前缀/后缀全文：

```
这是一张美甲客照的保真修图任务。输出必须与原图是同一张照片、同一构图、同一双手、同一背景，只做下面要求的调整。
【绝对不改】指甲的形状、长度、颜色、图案、贴钻位置和数量与原图完全一致；手的姿势、手指位置、手指粗细、关节位置不改；背景内容和构图不改；画面比例与原图一致。
【本次调整】{PRESET}
【输出】清晰度不低于原图，不做风格化，不加滤镜色，不加任何文字或水印。
```

| id | 名称 | {PRESET} 段 |
|---|---|---|
| p1 | 冷白皮 | 手部肤色调成干净的冷白皮，轻微提亮，降低橙红饱和度，保留皮肤真实纹理和指节褶皱，只减淡不抹平；清理甲缘死皮和指缝暗角；不能出现塑料感和假白。 |
| p2 | 暖奶油 | 整体调成柔和的暖奶油色调，肤色微暖不发黄，保留皮肤纹理，轻微胶片感，不加颗粒。 |
| p3 | 暗光救回 | 把整体曝光提到正常水平，阴影提亮不发灰，压噪，肤色还原正常，不改变光的方向。 |
| p4 | 去反光 | 去掉甲面上杂乱的多点反光和刺眼高光，每片甲面只保留一条自然的水光反射带；钻饰和亮片轻微提亮增加通透感，但形状和位置不变。 |
| p5 | 背景虚化 | 背景只做轻微虚化和柔和的明暗渐变增加空间感，不换背景、不加东西、不去东西，手和指甲保持全清晰。 |
| p6 | 白平衡 | 校正白平衡，去掉偏黄或偏青，让白色物体回到中性白，指甲颜色还原到真实颜色。 |
| combo | 组合 | p6 + p3 + p4 + p1 + p5 按此顺序拼成**一条** prompt（验证多选拼接是否会叠加漂移） |

### 1.3 甲面贴回 PoC（只做 3 张）
挑 3 张样片，对 A 模型 p1 的结果做：用现成分割模型（rembg 或任意可用的手部/甲面分割）取甲面 mask → 把**原图甲面像素**贴回结果图 → 甲面区域做非生成式超分或锐化（Real-ESRGAN 或 OpenCV 都行）。产出前/后/贴回三联图。只回答一个问题：拼接边自然不自然。

## 5. 补充（09-22 下午）· 样片格式
- 店主样片多为 iPhone 实况照片：`.HEIC` + 同名 `.MOV`。脚本第一步先做**输入归一化**：`.MOV` 直接忽略；`.HEIC` 转 `.JPG`（质量 92，按 EXIF 方向转正后再存，去掉方向标记），长边 ≤ 4096；`.JPG/.PNG` 原样。归一化后的图存 `31o_修图验证_2026-09-22/_input/`，对比包和 COS 上传都用归一化后的文件。
- 转换用 Python `pillow-heif` 或 Node `sharp`（需 libheif）；Mac 本机也可直接 `sips -s format jpeg`。
- **这条同样写进后续正式功能的口径**：后端收到任何图先归一化（HEIC→JPG、方向转正、长边上限），再送模型；小程序端 `wx.chooseMedia` 在 iOS 上通常已自动转 JPG，但后端不能依赖它。
