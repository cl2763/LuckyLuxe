## 🔴 先回答你那个误区

> **「功能全做完才能提审」—— 不是,而且方向正好反了。**

审核看的是:**提交的那一版能不能正常打开 · 有没有违规内容 · 类目对不对 · 有没有诱导欺骗**。
**它不看你功能全不全。** 而且小程序**每次更新都要重新审一次** —— 所以「先上一个能用的,再边用边优化」本来就是这套东西的正常用法。

🔴 **第一次提审最容易卡的是类目/资质这类流程性的东西,而这些坑只有真提一次才会暴露。早提一次,比等功能做完划算。**

## 二 🔴 类目 / 资质 —— 这一条只有你能办,而且最容易卡

**美业一般落在「丽人」类目。** 平台通常会要:
- **营业执照**(经营范围要覆盖美甲美睫这类服务)
- **门店照片 / 地址**(有些子类要)
- 若涉及「预约到店服务」,可能要额外的服务类目说明

🔴 **我不能替你判断该选哪个子类** —— 那取决于你营业执照上写的经营范围,选错了会被打回。
**建议:先去平台的「服务类目」页把候选列出来,截图给我,我帮你对着经营范围挑。**

## 三 提审那一版**必须跑通**的路(我负责验)

```
进店 → 看服务 → 预约 → 我的 → 看订单 → 看结算单 → 看签署文件
```
**这七步每一步都要能打开、有内容、不报错。** 我会在提审前逐步实点一遍并留证据。

## 四 🔴 这一版**可以不全**的,以及它们该长什么样

**判别式(审核最常挂在这上面):那一版里不许有「点进去是空的 / 报错 / 假数据」的入口。**
**做不完的要藏起来,而不是留一个空页面。**

| 功能 | 建议这一版怎么处理 | 理由 |
|---|---|---|
| **商城自助购买** | 🔴 **藏掉入口** | 支付通道未接通(`PAYMENT_CHANNEL_READY = false`),点进去会拒 —— 那是「点进去报错」 |
| **积分商城 / 积分账本** | 可留,但要保证空态有话说 | 已有空态文案;**我会实点确认不是白屏** |
| **站内消息** | 🔴 **藏掉或确认有真内容** | 没有真数据时它就是个空壳 |
| **门店导航** | 留 | 门店信息是真的(地址/营业时间) |
| **AI 客服** | 留 | 已接真模型;**但我要确认没配额时的兜底话术不是报错** |

🔴 **「藏掉」怎么做,以及藏哪几个,等你点头我再动** —— 那是产品决定,不是我能替你定的。

## 五 建议的顺序

1. **你现在就能做的**:去平台看类目候选 + 准备营业执照 → 截图给我
2. **同时进行**:§三 拿域名 + 开机器(第 2 条卡在这儿)
