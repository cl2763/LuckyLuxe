# 小批 12n 补二(修图对话)—— 甲色口径:去高光后的中位数;D222 数量以立项文档为准

## §一 口径裁定(量法,不是门槛;趁 23 张没标完先定,不看数据定)
要量的是「这块甲油本身是什么颜色」。均值会被亮面高光拉亮(02 黑甲的问题),低分位会被甲缘阴影、甲沟拉暗(换个方向错)。
**定:甲面 Y 与 C 一律取「去高光后的中位数」** —— 在每片甲面掩膜内,先去掉 Y 高于该片 p85 的像素(高光),再取剩余像素 Y 的中位数、C 的中位数;整张 = 各片中位数的中位数。
- 写进 `nail-tier.json` 的 `metric` 字段(`"median_after_p85_trim"`),两支(粗估、真掩膜)都读它,不许各写各的。
- 已标 4 张用新口径重算,**旧均值与新值并排列在分档表里**,不删旧数。
- **门槛(浅 90 / 纯黑 35 / 鲜明 25)一个都不动**,等 23 张用新口径出分布后再给店主看。若新口径下 23 号仍落在 90 以下,那是门槛的事,到时一起定。

## §二 D222 数量:以立项文档的区间为准
「300 张起步」是我在 12h §三 随口给的估数,没有来源;D222 立项文档里 Code 按组成给的 **800–3,000 张**才是有依据的数。**两个数不许同时活着 —— 以 D222 文档为准**,12h 与 12n 补里的「300」作废(我改)。
可以保留的区分:**验收集**(三档各 ≥ 20 张,12h §三 判据)与**训练集**(800–3,000)是两件事,D222 文档里分两行写清。
