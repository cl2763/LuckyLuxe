## 四 那张图说了三件事(这是你定门槛真正要看的)

### ① 色度这把尺对「鲜明」本身很干净
**七张人眼判「深·鲜明」的,C 全在 26.9 以上**(69 号 26.9 是最低的一个),
而所有「不鲜明 / 纯黑」的 C 都 ≤ 12.8。**C 门槛 25 站的位置是对的,中间是一大片空白。**

### ② 但裸甲也在线上面 —— 靠亮度才排除得掉
42 号裸甲 C 37.2、43 号裸粉 C 41.9,**比 87 号砖红甲(37.6)还高**。
它们没被判成「鲜明」,靠的是 Y 156–157 先被「浅」接走。
**所以「浅优先」不能取消**(这一条上一节已经验过)。

### ③ 🔴 可是这样就救不了 53 号,而且有一对点**根本分不开**
- 53 号(荧光,Y 103 / C 59.2)被「浅」抢走 —— 要救它,Y 门槛得抬到 103 以上;
  可 51 号(银甲,Y 110)人眼是「浅」,抬到 110 就把它判错。**中间只剩 103–110 这 7 分的缝。**
- 更硬的一条:**23 号(浅,Y 68.5 / C 6.8)与 65 号(混,Y 67.5 / C 6.1)几乎是同一个点。**
  人眼判的是两回事,而这两个数一模一样 —— **不管门槛怎么定,(Y, C) 这两个数永远分不开它们。**

**结论(不是建议,是这 23 张数据的形状)**:
**「单一 Y 门槛 + 单一 C 门槛 + 浅优先」这套判法,在这 23 张上做不到全对。**
差的不是几分,是**信息不够** —— 需要第三个量,或者换一种汇总方式。
这正好对上你登记的两条候选:
- **「离肤色有多远」** → 给「鲜明」换一把不跟裸甲混的尺(可能连 42/43 都不用靠亮度排除);
- **「逐片判档」** → 65 号那种混色张不再被中位数抹平(23 vs 65 那对同点也就不同命了)。

**三个门槛我一个没动,判法顺序也没动。** 两条候选仍是「未启用」,验收条件早就写死。
