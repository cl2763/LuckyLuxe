## 六 · 判据(10b §四 七条,每条两面验)

| # | 断言 | 反向守 |
|---|---|---|
| 6.1 | **删不掉**:任何路径都不能让一行 `signed_docs` 消失 | 真写一条 DELETE 进去 → 必须红 |
| 6.2 | **作废留痕**:`voided_at`/`voided_by`/`void_reason` 三样齐 | 少一样红 |
| 6.3 | **越店拿不到**:A 店拿 B 店 doc_id → 拒 | 🔴 造得出阳性(J-58①) |
| 6.4 | **顾客只拿自己的**:顾客 X 拿 Y 的 → 拒(**店 + 本人两个条件都判**) | 同店他人 / 他店本人 各一条 |
| 6.5 | **顾客端拿不到作废的、拿不到 `customer_visible=0` 的** | 换 owner 令牌必须拿得到 |
| 6.6 | **不登录拿不到**(D194/D201 同族) | 带令牌必须 200 |
| 6.7 | **多页顺序稳定**,页数对得上 | 乱序插入后仍按 page_no 出 |
| 6.8 | 技师只限**自己服务过的**顾客(照抄小记那把锁) | 服务过 → 200;没服务过 → 404 |

## 八 · 假设清单(图上没画到的,按最合理做并记在这儿)

1. **机器名 `pricelist`**(图上只有显示名)—— 理由见顶部,等裁。
2. 建表用 `CREATE TABLE IF NOT EXISTS`(全新表无存量),但**配 `test-schema-consistency` 断言**;列一律 `try/catch ALTER`。
3. 文件存储复用签署快照那一套(COS 优先,失败 inline 入库),**不落卷上文件系统**。
4. `customer_visible` 列本批**建但不给顾客端读**(第二步才接顾客端)—— 列先在,口径先定死。
5. 缩略图:本批用第 1 页原图缩放,不另做缩略图管线。
