## ② 后端:唯一来源 + 3 个用处

```
local-server.mjs:394

```
**用在且只用在 3 处:**

| 行 | 生成什么 | 会到谁手里 |
|---|---|---|
| `:5461` | `referralUrl` —— 推荐链接 `/?ref=REF-…` | 顾客分享给朋友 |
| `:10042` | **签署链接** `/sign?t=<token>` | 🔴 顾客点它去签结算单 |

🟢 **好消息:它是 env 优先的。** 要切域名**不用改代码**,改 Railway 的 `APP_PUBLIC_URL` 就行。
🔴 **但 Railway 的变量我不碰(停线)** —— 这一条要你裁了我再报给你怎么改,或你自己在面板改。

## ③ 会话 / Cookie:不会互相踢

```
platform-session.mjs:43   flags = ['HttpOnly', 'Path=/', `Max-Age=…`, 'SameSite=Strict']
```
**没有 `Domain=` 属性** ⇒ host-only cookie,**两个域名各有各的一份,互不影响**。
顾客侧不用 cookie(用 `localStorage` + Bearer 令牌),同样不受影响。

## ④ CORS:全仓没有白名单

`Access-Control-Allow-Origin` / `allowedOrigins` / `ALLOW_ORIGIN` → **0 处**。
⇒ 加域名不会被 CORS 拦。
🟡 **反过来说也值得记一笔**:后端没有 origin 白名单。**今天不是问题**(所有口都要 Bearer 令牌,没有靠 cookie 的跨站写),**但它是一条以后可能要补的护栏**,单独登记。
