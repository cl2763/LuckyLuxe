## 一、她看到的是什么(我按图说,不猜)

`localhost:4310/admin` → 侧栏「财务」,深色档:

- **对的**:侧栏、顶栏、四张数字卡(本日收款 / 本月收入 / 本月支出 / 本月净赚)、AI 智能总结那条(浅底 + 深字,可读)——**这些都跟上了**;

## 二、🔴 真正要裁的不是这一处,是**判据为什么没咬住它**

J-36 立的时候写的是「正文对比度 ≥4.5:1」,但**实现只在两张截图上取了四个点**(`--heroink/--herosub/--brandd` 那几个)。于是:

> 一个页面可以**四个取样点全绿**,而它旁边那块面板白字压浅底 —— 判据不红,店主眼睛红。

**这正是 J-37「在缺陷存在时照样绿的判据就是废判据」的又一例**,只不过上次是「在不在 ≠ 看得见」,这次是「取样点绿 ≠ 整页可读」。

**裁 · J-36 升级(这一批第一件)**:

1. **逐页逐元素全扫**,不再取样点:用 CDP 遍历后台**每一个页面**(侧栏 11 项 × 每页内部的标签页,财务那种还要进「趋势 / 记一笔 / 储值卡 / 日结 / 员工工资 / 流水 / 财务设置 / AI 解读」每一格),在**浅 / 深两档**下,对**所有可见文字节点**:
   - 取 computed `color`;
   - 取它**实际绘制的背景**(自身背景透明就往上找第一个非透明的祖先);
   - 算对比度,**< 4.5:1 即红**(大字号按 WCAG 放宽到 3:1,要在报告里标明用的是哪一档门槛)。
2. **红榜要能直接照着修**:每条打印 `页面 · 标签页 · 档位 · 选择器 · 文字前 20 字 · 前景色 · 背景色 · 比值`。
3. **造病**:把 `#financeTrendTitle` 的颜色改成 `var(--ink)` 而底色保持浅灰 → 当场红并点名这一条;还原后绿。
4. **上棘轮**:第一次跑出来的红条数**就是底数,只许降不许升**(和写死色棘轮同向)。**这一批不要求清零** —— 要求的是「**从今往后没人能再悄悄多加一条**」,以及**把店主这一页先修好**。

## 三、`styles.css` 那 384 个字面色:**先改「面」,再改「字」**

现查 384 个字面色里,造成「看不见」的是**做面的那些**(`background` / `border`),不是做字的。所以顺序不是从头改到尾:

1. **第一轮只改「面」**:`background` / `background-color` / `border-*` 上的字面色 → 读令牌(`--paper` / `--card` / `--wall` / `--line` / `--hero`)。面一改,白字压浅底这一类**成片消失**。
2. **第二轮再改「字」**:`color` 上的字面色 → `--ink` / `--sub` / `--heroink` 等。
3. 两轮各自报「改了多少条、棘轮从几降到几」;**值只从 `design-tokens.css` 出**(那份是从合同图逐字符搬的,不许在这一步顺手调色)。
4. `admin.js` 里那 23 个内联字面色**一并纳入**同一把刀的扫描范围(它们是内联样式,静态扫 CSS 文件扫不到,别漏)。
