## 店主原话归纳(以此为准)
1. 要一个功能叫**「质感增强」**:甲上**闪亮的部分更闪亮**;**每种颜色调到它最该有的质感状态** —— 按色调分别调。
2. 实际客照常有**发灰、糊、光线差**的,这类样片不多 → **拿她给的好照片人为加坏,再让修复流程去救**,验「不管给什么照片,都能修到比较还原真实、光影好看的程度」。

## 一 质感增强 = 12q 甲面层的升级版
- **按片判色系**(不是整张;一张里可以有黑有银有裸)。色系先分六类,起手规则写进 `enhance-preset.json`,按 Y/C/色相判,判不准的片标「未判」走通用档:
  | 色系 | 质感目标(起手) |
  |---|---|
  | 纯黑 | 镜面感:提高光与反差,不提饱和 |
  | 红 / 酒红 | 厚度感:暗部保色、中间调略提饱和,高光不发白 |
  | 裸 / 奶白 / 浅粉 | 通透:轻提亮、压灰,饱和几乎不动 |
  | 荧光 / 高彩 | 鲜而不溢:vibrance 为主,限幅防溢色 |
  | 金属 / 银 / 珠光 | 闪:加强细小高光点 |
  | 猫眼 / 闪粉 | 光带与闪点:只加亮已有的亮带与亮点 |
- **「闪亮更闪亮」的做法**:在甲面掩膜内找**已有**的高光(亮度高、色度低的小区域),只对它们局部提亮/提锐。**不许凭空加高光**(那就不是还原真实了)。
- 12q 的「真实还原」判据照旧(甲油色相偏移 ≤ 3°、甲面梯度方向一致 ≥ 0.95),每个色系分开报。
- 第八轮对比包里「甲面·中/强」两格就用这套按色系的质感增强。每行标上每片判成了什么色系。

## 二 退化测试集(好图加坏 → 修复 → 跟好图比)
**挑好图**:从 88 张里挑 **10 张拍得好的**(曝光正常、清楚、色准),四档都要有;理由写 `_退化集挑图.md`。好图 = 「标准答案」。
**加坏**(每张每种 1–2 个强度,脚本固定随机种子,可复现):
| 坏法 | 强度 |
|---|---|
| 欠曝 | −1 / −2 档 |
| 过曝 | +1 档 |
| 偏黄(室内灯)/ 偏蓝(阴天) | 各轻/重 |
| 发灰(低对比+雾) | 轻/重 |
| 轻微失焦 | 轻/重 |
| 手抖 | 轻 |
| 噪点(暗光高感光) | 轻/重 |
| 「随手拍」组合 | 欠曝+偏黄+噪点+轻糊 |
**修复**:用 12q 的整体层 + 自动白平衡 / 自动曝光 / 去灰 / 降噪 / 锐化,**只用确定性处理**,修复流程**不许看到好图**(只能看坏图)。
**量**:修复图对好图 —— 甲面区色差(ΔE 中位)、甲面区结构相似度、全图亮度差;并排报「坏图对好图」的同一组数。每种坏法给结论:**救回 / 部分救回 / 救不回**(救回的标准写在回执里,先写后跑)。
**实话要求**:糊得重的、光线本身差的,确定性处理大概率救不回 —— 救不回就如实写「救不回」,不许挑好看的报。
**对比包** `round8b_退化修复_2026-09-24/对比包_退化修复.html`:每行 好图 | 坏图 | 修复图 + 三个数;可点反馈;无人脸。
