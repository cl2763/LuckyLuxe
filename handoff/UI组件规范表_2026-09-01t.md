# UI 组件规范表(01t 二,立为合同;2026-09-01)

> 依据=全端扫描现状(附件:/tmp/ui-scan.txt 归档 handoff/attachments/UI扫描_2026-09-01.txt)。
> 裁定原则:**每类一种标准形,取现存主导形制**(改动面最小、与店主已裁的「台面黑白」语言一致)。
> 本批只立法+改店主点名处;全站清扫=队尾 UI 总审批。规范断言常驻(test-ui-spec)。
> ⚠️ 此表按 01t 指令由 Code 依扫描主导形制拟定,**每类标准形请店主终裁**;裁定不同者按裁改表+改断言。

## 现状(扫描数字)

| 类 | 网页现存形制 | 小程序现存形制 |
|---|---|---|
| 按钮圆角 | **8 种**(999px×11 / 8px×11 / 14px / 50% / 10px / 16px / 5px…) | **12 种**(999rpx×33 / 16rpx×16 / 14rpx×12 / 40rpx×11…) |
| 输入框圆角 | 5 种(8px×22 主导) | 7 种(12rpx 主导) |
| 开关 | 实质标准已存在=营业时间那颗(34×20 胶囊拨杆),但值日用了裸 checkbox、通知用 label 包 checkbox | wx switch + 自绘混用 |

## 标准形(每类一种)

| 类 | 标准 | 依据 |
|---|---|---|
| **主操作按钮** | 网页 `.primary`(圆角 8px·min-h 46·slim 变体)/ 小程序 `.btn` 圆角 16rpx | 两端各自主导形;8px≈16rpx 跨端同视觉 |
| **次按钮/切换** | 网页 `.ghost`/`.toggle` 999px 胶囊 min-h 38 / 小程序胶囊 999rpx | 主导形(999 系两端合计 ×44) |
| **chips(筛选/选择)** | **999 胶囊;选中=黑底白字(#1f1b16 系)**,未选=白底描边 | 店主已裁的台面黑白规格,推广为唯一选中语 |
| **输入框** | 网页 8px / 小程序 12rpx;`type=text + inputmode`(钱框既有红线) | 主导形(×22 / ×4) |
| **开关** | **`.ui-sw`(=营业时间 hsw-sw 同一条 CSS 规则的别名)** 34×20 胶囊拨杆,行右侧放置;小程序用 wx switch 或同形自绘 | 已存在的最完整开关,值日行本批已改用(D98) |
| **设置行** | `.settings-item`:summary 16px 行距,标题左/值右/▾;行内说明=12.5px muted | 门店设置页既有 |
| **卡内行距** | 网页 padding 10–14px、行距 8–10px;小程序行 20–24rpx 上下 + 22rpx 左右(=.row 规格) | D99 依此改 |

## 本批已照规范改的点名处

- 值日设置行 → `.ui-sw` 行右开关 + 行内小字(D98)
- chips 三处圆角统一 999px(.sw-chip 16→999 / .rfm-chip 14→999 / .nfy-chips 5→999)(D100)
- 小程序值日 chips → 999rpx 胶囊 + 选中黑白 + 呼吸(D94)
- 定金规则摘要行 → .row 规格(D99)
- 阈值编辑器 → 横排一行(店主裁定)

## 常驻断言(test-ui-spec,白名单判据)

按钮/チップ类选择器的 border-radius 必须 ∈ 规范集 {8px, 999px, 50%(圆点), 16rpx, 999rpx};
**存量未清扫处进白名单逐条挂账(带条目数棘轮,只减不增)**;新增面用规范外形制 → 红。
