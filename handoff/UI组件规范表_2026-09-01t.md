# UI 组件规范表 —— 二形法(店主 2026-09-01 **01u 终裁**,即为合同)

> **一句话规矩:能点的都是胶囊,能装内容的是圆角矩形。**
> 立法背景=店主原话「有的按钮是方角边,有的是圆角边」。上一版按"现存主导形制"拟,主操作 8px、
> 次按钮 999 两形并存 —— 那正是她骂的那件事的成因。终裁改为二形法:一句话规矩,谁都不会记错,
> 新面也不会长歪;且与台面/页签已有的黑白胶囊语言同族。

## 法条

| 面 | 形 | 说明 |
|---|---|---|
| **一切按钮**:主操作 / 次操作 / 切换 / chips / 页签 / **整宽主操作条**(「确认日结」「保存」) | **999px(网页) · 999rpx(小程序)胶囊** | 选中态=**黑底白字**(#1f1b16 系),未选=白底描边 |
| **输入框 / 卡片 / 面板 / 行容器** | **网页 8px · 小程序 12rpx 圆角矩形** | "能装内容"的一侧 |
| **开关** | `.ui-sw` 34×20 胶囊拨杆,**行右侧**放置 | 本就是胶囊族,与法条一致 |
| **例外白名单(只两项)** | ①圆点/头像 `50%` ②系统组件(`wx switch`)自带形 | 不得扩充 |

## 常驻断言 `test-ui-spec`(10 项,两层判据)

| 层 | 判据 | 强度 |
|---|---|---|
| ①③ **形制集** | 容器侧存量条数**棘轮**(网页 ≤58 / 小程序 ≤289,只减不增) | 挂账,总审批时清 |
| ②④ **按钮必胶囊** | 按钮族选择器**必须 999** —— **硬零** | 二形法的牙齿 |
| ⑤⑥ | 按钮层挂账位棘轮(容器/徽标误命中,只许降) | 棘轮 |
| ⑦–⑩ | 主操作 / 开关单一真相 / 值日行 / 值日 chips 四处点名 | 属性界定钉死 |

**为什么要两层**:形制集单层挡不住二形法 —— 8px 在集合里,`.primary` 退回 8px 它照样绿。
**刀证**:`.primary` 999px→8px(还原成她骂的那个方角)→ ②层红且报出是哪一处;
**归因**:同一刀喂①层(旧式形制集)**是绿的** —— 证明新层在真守,不是数量凑巧。字节还原后回绿。

## 交叉态(店主 01v 两小裁,**已定,不必再问**)

**① 可点的内容卡**(`.recommend-card` / `.quick-item` 一类:整张卡是 `<button>`,里面装图+文+价):
> **整张卡装着图文内容的,按容器算,不按按钮算;二形法管的是控件,不是内容卡。**

维持圆角矩形(网页 8px / 小程序 12rpx)。判据侧一致(扫描器的按钮词不命中这类选择器)。

**② 展示型徽标**(`.member-code-chip` 一类):**不是控件,不归二形法管**;形制在队尾 UI 总审时统一定。
