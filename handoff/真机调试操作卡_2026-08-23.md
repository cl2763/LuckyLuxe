# 真机调试操作卡(店主用 · 2026-08-23)

## 为什么以前登不上
手机上的 `127.0.0.1` 指的是**手机自己**,不是你的 Mac —— 所以手机怎么点都连不到 Mac 上的沙箱服务。
已修:①本机服务改成局域网可达;②小程序**自动**识别「在模拟器里跑」还是「在手机上跑」,分别用回环地址 / Mac 局域网 IP。

## 三步(第一次做完,以后只做第 3 步)

1. **勾一次「不校验合法域名」**
   微信开发者工具 → 右上角 **详情** → **本地设置** → 勾上
   **「不校验合法域名、web-view(业务域名)、TLS 版本以及 HTTPS 证书」**。
   (沙箱是 http 明文,不勾这个手机会直接拒连。)

2. **确认手机和 Mac 连同一个 Wi-Fi**(不是手机流量,也不能一个连 5G 一个连 2.4G 的访客网络)。

3. **点工具栏「真机调试」→ 手机微信扫码**,手机上就会打开小程序。

## 换了网络 / 连不上时
双击项目根目录的 **`更新真机调试地址.command`** —— 它会把 Mac 当前局域网 IP 写进小程序配置,并当场自检回一句
`{"ok":true,...}`。回不了这句话,基本是 Mac 防火墙挡了:**系统设置 → 网络 → 防火墙 → 允许 node 接入**。

当前地址:**http://192.168.0.104:4310**(沙箱库,演示数据;真库那台 4128 不动)
