### c3 小程序顾客端零回落补扫(通则提炼律)

D71 当时只扫了网页,小程序**映射层**漏了四处,一处比一处重:

```
- depositCents: booking.depositCents || 0          ← 没有值变成"零元"
- payableAmount: booking.depositCents ? … : 0      ← 同上
- finalDue: booking.finalDue || 0                  ← 同上
- servicePrice: booking.servicePrice || service.price || 0   ← 还拿别的字段顶上
```
**第三宗罪最阴**:页面层明明写了「`!== null` 才显示,否则 —」,被映射层的 `|| 0` 堵死,
那句「—」**永远走不到**。现在四处全改 `== null ? null : 值`,页面那句才活过来。
反例正例都真跑:全空 → 四项皆 null;有值 → 原样透传(没把真值也改没)。
