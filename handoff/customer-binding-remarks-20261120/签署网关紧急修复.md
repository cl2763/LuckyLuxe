# 服务单国内域名转发缺失：已修复

2026-11-20 22:57（北京时间）完成。用户报告打开结算单出现 HTML 非 JSON 错误。

- 根因：国内 app 与 api 两个 Nginx 白名单缺少 `/member-document-groups` 和 `/member-documents`，真实用户打开服务单时前者被 Nginx 返回 404 HTML，未到达后端。
- 操作：读取当前线上两份配置，各备份原文件；仅新增这两个路由前缀。变更前后 `nginx -t` 通过，使用 reload，未 restart。网站官网配置未修改。
- 验收：原失败页面携原访问凭证重读 200 JSON，实际页面恢复“服务确认单”、确认勾选与手写签名框，单据仍 pending_sign、无需重新核价。未代签。
- 三个域名的健康、读取不存在单据、提交不存在单据共9项通路复验均收到预期JSON；测试请求不创建单据或资金记录。见 gateway-verification.json。
- 额外检查：两个国内域名的 sandbox、wechat-simulator 和相似但未授权前缀仍返回404，未扩大到任意路由；公司官网仍200。
- 数据保护：本次只有反代配置变化，无应用升级、数据库连接、迁移或任何商家记录修改。配置已在服务器及本机私有隔离目录保存备份。业务数据/签署令牌不写入本报告。
- 发布状态：这项营业故障已在线修复；备注名及绑定入口仍为独立待验收批次，尚未全门店发布。
- 测试漏项：此前只验证后端/原域名和页面资源，未覆盖国内网关的新版完整签署接口。后续发布验收必须分别验证国内网页与小程序域名，不以 Railway 接口正常代替国内入口正常。
