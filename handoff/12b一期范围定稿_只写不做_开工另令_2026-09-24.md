# 12b 一期范围定稿(12h)—— **只写不做,开工另令**

依据:12a 五轮 + 12g 分割验准。每条「不做」都有反证,见 `12a_结论书_2026-09-24.md`。

## 一、一期做什么

| # | 做什么 | 怎么做 | 依据 |
|---|---|---|---|
| 1 | **模型口令 = 腿 A′ 那版** | 四块结构:【绝对不改】【甲面】【手部皮肤=只去瑕疵】【曝光】。<br>代码在 `tools/ai-retouch-eval/round5-prompts.mjs` 的 `promptR5b()`,配 `check-round5b.mjs` 自检 | 模型只做得了去瑕疵 + 甲面保护 |
| 2 | **分桶 = 手框亮度 × 甲面深浅** | 曝光维按**手框均亮**(不是全图均亮)· 甲面维分深/浅。<br>`bucketOfSkin()` + 深甲句/浅甲句 | 手框均亮与模型提亮幅度秩相关 **−1.000**;全图只有 −0.600 |
| 3 | **亮度回贴,默认 100%** | 商家可选 **100 / 50 / 0**。100 = LM-YC(Y+色度都回贴) | 23 号死白 26.66%→**0%**、15 号 13.41%→**0.2%** |
| 4 | **比例:原图 / 3:4 / 9:16** | 非生成式裁切,`crop-ratio.mjs`,¥0,甲面零改动 | 店主 12e §一 定 |
| 5 | **版权拒稿 → 提示商家换图** | 错误文本含 `copyright` → 不计张、不重试、给人话:<br>「这张含版权图案(卡通角色等),模型不接,请换一张或跳过」 | Hello Kitty 实测 HTTP 400 |

## 二、一期不做什么(每条都有反证)

| 不做 | 为什么 |
|---|---|
| **手部冷白 / 磨皮** | 五轮全部反效果。腿 A′ 把「冷白/磨皮」四字全删,皮肤照样被拉冷(R:B 差 −0.04~−0.31),<br>肌理**比原图更高** 1.25–2.66 倍 —— 模型在加纹理不是磨 |
| **甲面贴回** | 需要甲面分割。红甲/裸甲**人给框都圈不出**(14 号掩膜 100% 肤色) |
| **换背景** | 口令写着「手与指甲每一处细节不变」,44 号立体钻仍被重画;手框 diff 15.7–93.6。<br>要做必须「先定稿主体 → 换背景 → 主体整块贴回」三步,第 3 步依赖分割(D222) |

## 三、🔴 产品文案不许承诺这四件

1. **暗片不提亮** —— 桶 A 明写「不要整体提亮」,28 号仍 **+198%**
2. **磨皮** —— 五轮反效果
3. **美白** —— 皮肤色调模型不受控,一期靠回贴**拉回原图**,不是做白
4. **换背景主体不变** —— 44 号立体钻被重画有实证

## 四、开工前置(三件不齐不许排期)

1. **D217 AI 包开关**
2. **生产 CPU 耗时实测** —— 本机 M4 Pro 的数不算;分割纯 CPU 0.73 秒只是上限参考
3. **计费口径** —— 每张 **¥0.32 + 加成**,**加成由店主定**

## 五、流程定稿(12e §七,次序不许颠倒不许合并)

量(手框 / 全图)→ 分桶(曝光 × 甲面色调)→ 模型(四块口令)→ 亮度回贴(α)
→ 〔二期〕皮肤层(掩膜内)→ 〔二期〕甲面/背景取回贴件 → 〔二期〕换背景 + 主体贴回
