## 一 真根因(量出来的,不是推出来的 —— J-88)

我在那台 Linux(`Linux 6.8.0-136-generic`)上做了一次**干净 clone 复现**,而不是在店主的工作树里跑:

```
git clone --depth 1 file://.../new-chat repo
cd repo && bash tools/pre-regression.sh   →  exit=1
```

**量出来的结果:**

| 项 | 干净 clone(= CI) | 店主 Mac 工作树 |
|---|---|---|
| `ls -t 对比度红榜_*后台*.md ... \| head -1` 挑中 | **`对比度红榜_修后_2026-09-09.md`** | `对比度红榜_07f后_后台_折opacity_2026-09-13.md` |
| 那份记的指纹 | `57a36354a321` | `c3df1fc7ecf7` |
| 现算 `NOW_SHA`(`:254`) | `c3df1fc7ecf7` | `c3df1fc7ecf7` |
| `:257` 判决 | 🔴 **对比度全扫过期了** `FAIL=1` | ✅ 一致 |
| `:270` D188 同理:挑中 `D188运行判据_2026-09-12.md` 记 `50c1075488c3`,现算 `06c156ad1268` | 🔴 `FAIL=1` | ✅(挑中 09-16 那份,记的正是 `06c156ad1268`) |

**机理:`ls -t` 按 mtime 排序。干净 checkout 上,所有文件的 mtime 都是签出的那一瞬间,彼此相等 —— 排序结果是任意的,跟「哪份报告最新」毫无关系。** 店主机器上 mtime 恰好等于生成顺序,所以一直是绿的。

**三项旁证全对上:** exit code **1**(不是 2、不是 127)· step 5 耗时 **11 秒**(预检整段跑完了,不是秒退)· **Mac 绿 / CI 红**。

外部件那三条(automator / 9420 / Chrome)在干净 clone 上也红,但 `:87` 明写 **⚠️ 提醒(不拦)**,不进 `FAIL` —— 不是它们。

## 三 这一次要改的(挡推)

**`tools/pre-regression.sh` 两处,`:251` 与 `:264`:不许再用 `ls -t` 挑「最新」。**

换成**按内容问真正要问的那个问题**:「**这套界面,有没有任何一份报告扫过?**」

```sh
NOW_SHA=$(cat apps/web/styles.css apps/web/admin.html apps/web/admin.js | shasum -a 256 | cut -c1-12)
HIT=$(grep -l "界面文件内容指纹 \`$NOW_SHA\`" handoff/night-runs/对比度红榜_*.md 2>/dev/null | head -1)
[ -n "$HIT" ] && ✅ "用的是 $(basename "$HIT")" || 🔴 "现在这套界面($NOW_SHA)没有任何一份红榜扫过 —— 重跑 tools/contrast-sweep.mjs"
```

**我已经在那台 Linux 的干净 clone 上验过这把新尺子的两面(J-91):**
- 真指纹 `c3df1fc7ecf7` → 命中 `对比度红榜_07f后_后台_折opacity_2026-09-13.md` ✅
- 假指纹 `deadbeef1234` → 空 → 红 ✅ **它会咬人**

D188 那处(`:264`–`:273`)同款改法,扫 `D188运行判据_*.md`。

**这个改法顺带修好了一个更早的毛病**:老写法是「挑一份 × 看它过没过期」,**挑错了就冤枉人**;新写法是「问这套界面被扫过没有」,**这才是这道闸真正想问的事**。

### 立 J-97
> **`ls -t`/mtime 不是「新旧」的证据。** 干净 checkout 上所有文件的 mtime 都等于签出那一刻。凡判据要取「最新的那一份」,必须用**内容里的事实**或**文件名里的日期**,不许用 mtime。
> 上位法是 **J-95**:一个绿必须带着它是在哪台机器上量的 —— 这一条说的是**同一把尺子在两台机器上给出不同答案的具体机理**。
