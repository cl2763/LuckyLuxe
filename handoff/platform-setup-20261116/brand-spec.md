# 设计约定
模式：Extension，沿用现有平台后台。用户已要求基于真实现有页面补齐能力，不另加风格确认。
Design Read：平台配置工具／平台运营人员；米白底、金色重点、白色表单；差异1/10、动效1/10、密度7/10、素材依赖2/10、品牌保真10/10。
原始依据：apps/web/platform.html 与 apps/web/design-tokens.css。
Logo：miniprogram/assets/images/youji-logo.png，原图复制为 assets/youji-logo.png。
令牌：paper #faf8f3；ink #241f1a；line #e3e0d6；brand #b09468；brandd #8a6f45；card #fff。
布局保留：左侧200px导航、原品牌、商家配置入口与商家选择栏。新增模块在此内部组织，不重画顾客首页或商家首页。
字体沿用 -apple-system/PingFang SC/Microsoft YaHei；正文14px，标题20px。表单间距16px，卡片20px内边距；边框1px，卡片圆角14px，控件8px。信息多时增加页面高度，不缩小字或挤压。
新页面的任务：总览定位缺项；编辑页完成配置；复核页看差异；交付页明确分工。使用场景为电脑近距操作，温和且克制，不使用装饰图或营销封面。
所有数值和门店名均为明确标注的设计样例，不读取真实商家档案。原型按钮仅模拟本地反馈，不连接生产接口。
