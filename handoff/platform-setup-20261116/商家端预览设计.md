# 平台配置后，看见商家实际页面

用户补充于 2026-11-16：每个配置模块都需要知道配置完成后，商家那边显示什么。此文与 P21–P24 共同组成新增设计，尚未接入生产。

## 用户操作

每个配置页面右上角提供“预览商家端”。进入时自动携带当前门店、模块、配置草稿版本，不要求重新选择，也不要求输入商家密码。P21 的选择器用于切换查看方式，图中以充值套餐为例。

可切换：

- 当前已生效 / 应用本次草稿后 / 修改前后对比。
- 商家老板 / 普通员工；未授权模块显示没有入口，不展示老板专属数据。
- 商家网页版 / 小程序；版本未支持的字段明确显示“本端未提供”，不假造编辑按钮。

预览标题始终显示目标门店、配置版本、读取时间、客户端版本及草稿或正式状态。商家修改了当前配置时，旧预览标为待刷新，重新核对后再应用。

## 每类配置的展示落点

| 平台配置 | 商家网页看哪里 | 小程序看哪里 | 特别提示 |
|---|---|---|---|
| 门店资料、营业时间、指引 | 门店设置相应条目 | 门店信息、营业时间、到店指引 | 预览展示与编辑页分别看 |
| 展示服务与价格 | 服务与价目 → 上架服务 | 服务与目录 → 上架服务 | 顾客页面可作为附加预览，不能替代商家预览 |
| 结算目录、加项、价格类型 | 服务与价目 → 结算目录；开单选择项目 | 服务与目录；开单页 | 目录管理与实际开单价格分开预览；试算使用合成身份 |
| 充值套餐与赠品 | 会员与营销 → 充值；套餐编辑；充值确认 | 会员套餐 → 充值；套餐编辑；账户调整 | 列表目前不显示默认个人折扣，不能误报未生效 |
| 次卡 | 次卡列表、编辑、开单核销选择 | 会员次卡；开单核销选择 | 编辑器字段差异要展示；不能修改已售卡快照 |
| 优惠券与积分 | 对应模板、兑换品列表及编辑 | 对应会员页签和积分管理 | 预览配置不会发券、兑换或撤销权益 |
| 会员制度 | 会员体系摘要（只读） | 会员体系摘要（只读） | 老板不能直接改平台管理的资格与等级 |
| 预约、定金与取消 | 门店设置规则编辑及业务摘要 | 门店规则摘要、预约订单 | 本端只有摘要时，不额外画可编辑按钮 |
| 通知与回访 | 通知设置、模板预览 | 通知与回访 | 预览不发送；订阅权限和送达状态单独验证 |
| 技师、员工、排班 | 员工管理相关页签 | 员工管理、排班 | 查看老板和员工不同入口；不读无关敏感档案 |
| 薪资、目标、固定费用 | 员工管理及财务对应设置 | 已支持的对应页，缺项明确标示 | 平台需要明确委托范围；预览不锁工资、不记账 |
| 知识库与客服接入 | 门店设置 → 本店知识、客服 | 已有摘要及接入入口 | 填写成功不代表消息通道已联通 |
| 顾客迁移、分层 | 顾客档案、分层、待核对权益 | 客户库与允许的档案视图 | 默认用脱敏摘要；不能通过预览冒充顾客身份 |
| 本人密码与授权 | 完成状态和操作说明 | 本人账号页说明 | 不展示密码、验证码，不代替绑定或授权 |

## 渲染与安全要求

1. 网页预览应复用商家真实页面组件、数据结构和校验规则，换成只读或草稿数据提供方；不长期维护第二份容易失真的页面。
2. 小程序不能简单塞进网页 iframe 冒充原生。需要按目标版本渲染，并与原生页面校验；当前交付 P23 仅为按现有 WXML/WXSS 转绘的 UI 设计，不是原生功能验收。
3. 预览访问需要平台权限、明确目标门店和限定模块；服务端执行只读限制，不能仅靠前端禁用按钮。模拟员工身份只缩小可见范围，不发放真实员工或老板凭证。
4. 点击商家界面中的编辑、充值、发券、签署、收款、发薪等动作，只能进入隔离预览或提示回到配置，不发起真实交易。外部通知／支付／上传等副作用也须阻断。
5. 草稿不改变营业数据；应用仍走字段差异、版本冲突检查、明确确认和留痕。预览成功不等于应用成功，反之亦然。
6. 无映射的模块、缺失数据、渲染失败、目标小程序版本不符，都显示明确状态，不能回退成假成功或另一家门店样例。
7. 预览容器中使用的角色、门店和配置版本变更时，旧预览内容清空并重新获取，防止串店。

## 本次设计证据与限制

- P22、P24 的商家网页内页使用本工作树 `admin.html` 会员模块、`admin.js` 的套餐列表渲染片段、网页样式及设计令牌；数据仅为标注过的设计样例。
- P23 的手机内页依据 `merchant/member/index.wxml` 与 `index.wxss` 转绘，不连接微信或生产账号。
- 所有原型操作只做本地导航和提示。尚未实现按任意模块动态渲染、保存草稿、跨角色服务端授权或真实应用配置；这些均是后续实施范围。
- 实施验收需逐模块核对老板／员工、网页／小程序、草稿／生效、空态／错误／无权限，并验证全部交易写入及通知副作用被服务端阻断。
