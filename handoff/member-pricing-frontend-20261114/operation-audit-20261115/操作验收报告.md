# 会员价格体系与预约定金 · 操作验收

本轮使用隔离合成门店、顾客和资金记录。网页原生点击、小程序开发者工具操作、页面模块测试与真实 HTTP 测试分开记录；不把接口通过称作实体手机或真实微信推送通过。代码尚未提交、推送或上线。

## 本轮发现并修复

1. 折扣滚轮内按钮与充值/退款外层确认共用选择器，导致外层提交或取消错绑。
2. 展示价格保存后列表未刷新；服务重开时分类丢失。
3. 冲销成功后账户弹层及折扣修订版本未刷新，下一笔操作可能冲突。
4. 套餐按钮兼容名称字段；小程序英文权益文案与参考价格提示重复问题。
5. 参考报价仍读旧结算价格；补齐只读展示报价接口及前端连接。
6. 小程序缺少按被服务者归档的独立服务单列表；补齐实际操作入口。
7. 日结更正链接不可可靠操作；改为真实按钮，修正异步点击处理。
8. 已自动退储值的金额更正仍提示现金找补；只提示剩余线下差额，并刷新客户余额。
9. 原价成交的单据标题仍写会员折扣；改为按实际所选价格类型展示，混合价档如实标注。
10. “改充值”文字点击会误触外层取消；改成独立按钮，保持已挂草稿。
11. 部分签署后重核价，刷新列表会拆开原服务组：复用后端原始组追溯，为两端入口保持完整本次服务，已签单与新待签单一起显示。旧待签版本不重复展示。
12. 新服务单列表按钮圆角不符合现有胶囊规范，已对齐；测试中发现的拆分模块加载/扫描路径也已迁移，原断言没有删除、门限没有放宽。

## 边界、异常与回归

新增 HTTP 检查覆盖无折扣/未设置、0.1与9.9、资格失效和恢复、同一次服务耗尽后的朋友单、其他服务耗尽后旧待签单重新核价、并发充值只有一个成功、幂等重试，以及只读参考报价拒绝资产或顾客参数。新增 DOM 层级检查专门守住嵌套滚轮按钮绑定，不用接口通过代替按钮验证。

变异验证保留在 [regression](regression/mutation-results.json)：临时副本故意破坏同次服务余额耗尽后的续签规则，旧测试通过而新增测试失败；故意恢复错误的嵌套选择器，新测试失败。修复代码恢复后均通过。未在生产或历史数据上注入故障。

最终e轮：主档213套/6528条、关闭演示登录权限43套、小程序自动化3套/16条，未执行0。比前次UI交付新增19条有效断言。完整回归日志哈希以 [回归摘要](../evidence/regression-summary.json) 为准。95个WXML编译通过。详细操作逐条见 [网页24类](web-operations.json) 和 [小程序操作记录](mini-operations.json)。记录包含页面SDK调用，不把每条都标成物理手点；初次改期被门店0次规则阻止的失败尝试保留，并关联允许规则下的后续成功证据。

## 尚不能宣称已完成的事项

- 没有实体手机上的微信绑定、授权、订阅消息送达和生产业务域名联调。开发者工具与共用签署网页的通过不代替这些结果。
- 没有把59组设计的118幅双端状态全部逐像素验收，完整原始交付清单也未批量打勾。已有实际图册与本轮操作证据只证明记录中的状态。
- 样式自动扫3364个文字节点未报对比度问题；182个渐变背景节点工具无法判定，未算成通过。
- 小程序独立服务单列表目前标明“最近100张”，不是全历史分页检索。
- 本轮没有生产请求、发布、生产备份/同运行时存量升级/重复启动核验，也没有操作历史本机库；不能据此宣称线上已更新或生产存量验证通过。
