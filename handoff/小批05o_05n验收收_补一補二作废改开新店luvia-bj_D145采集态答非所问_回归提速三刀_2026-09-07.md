## 二、🔴 D145 · 采集态答非所问(五通 v2 残留,一个病根)

我逐句读了 `05n_像人五通_原文_2026-09-06.md`:

| 通 | 顾客说 | 机器答 | 该怎样 |
|---|---|---|---|
| 一 | 「大概要多久」 | 「请问是否需要卸甲?」 | 先答时长(价目里有时长就报,没有就「一般 1.5–2.5 小时」出自知识库),再至多一问 |
| 一 | 「好的谢谢你啦」 | 「请问是否有断甲或需要修补?」 | 道别就收:一句「随时找我」,**不再问** |
| 二 | 「预算不多,能推荐吗」「那个最便宜的是哪种」 | 两次「是否需要下睫毛?」 | 报价目里最便宜的 1–2 项(数字走事实闸),再问一格 |
| 二 | 「会不会很快就掉」 | 「我先不继续反复追问啦…转给人工」 | 体验类:答「一般 3–4 周,看护理」(它在下一句其实会答),不转人工 |
| 三 | 「好的,就这个时间」 | 定金政策整段**第二遍** | 「定金规则同上」——病5 的这条没落到预约路 |
| 四 | 「还是改成美睫吧」「那周日行吗」 | 两次「大概几点方便?」 | 槽换了要**说出来**:「好的,改成美睫;周日可以,几点方便?」 |
| 五 | 「谢谢」 | 「想约哪天呢?」 | 同通一 |

病根一个:**采集态里,每一句顾客的话先过一道「这句是给槽、还是在问、还是在收尾」的分类,现在只认「给槽」**。⑫ 修的「让开」只覆盖模型判成「别的问题」那一种。

**修法**:collecting/quoting 两态统一走 `classifyTurn` → `slot | question | farewell | hesitate | budget`:`question` → 先答(事实槽/知识库/价目),再至多一问;`farewell` → 收尾不问;`hesitate` → 让开一轮;`budget` → 最便宜项;`slot` → 填并**复述变化**(「改成美睫了」「周日可以」);政策文本一会话一次(预约路也算)。

**判据(这次把五通变成常驻套件)**:`test-human-five.mjs`——五通脚本逐轮跑(沙箱真模型,`AI_REQUIRE_REAL`),每轮一条**可证伪**断言:含时长数字 / 不含「?」/ 含最便宜项名与价 / 不含「人工」/ 政策原文本会话第二次 0 命中 / 含「美睫」「周日」二字。造病:把 `classifyTurn` 退成只认 slot → 至少 4 条红。这套件跑真模型,只在**批末全量**时跑一次(见 §三),平时用 `SKIP` 计「本轮未跑」。

## 三、回归提速三刀(答店主「为什么一跑两个半小时」)

我数了:05n 一批跑了**五次全量回归**(20:34 / 21:16 / 00:51 / 01:22 / 02:55),每次约 15 分钟;其中三次红是**可预判的**(护栏清单没重生成、棘轮超、扫描面没跟着搬),红了再改再跑一遍;另外 老尺/新尺 三跑各 3 轮、200 句、五通 都是真模型,一轮一两分钟,加起来 40 分钟;剩下是 Code 自己改码与查因。**两个半小时不是回归慢,是同一批里重复跑了全量。**

1. **预检刀** `tools/pre-regression.sh`(< 1 分钟):重生成护栏清单 → 棘轮两数 → 全部静态扫描套件 → 断言基线只读比对;任一红就不起全量。`run-all-tests.sh` 开头**先跑它**;
2. **批内只跑相关套件,批末跑一次全量**:一批里的中间提交(a/b/c…)可以只跑改动波及的套件(`git diff --name-only` 映射),回执写清哪些;**交齐前必须一次全量绿**,且这一次的日志入仓——判据不变,只是次数;
3. **计时即证**:`run-all-tests.sh` 每套打印耗时、末尾打印总耗时与最慢 5 套;回执固定一行「全量 N 分钟 · 最慢:…」。慢套件 >3 分钟的列出来,下批看能不能拆。
