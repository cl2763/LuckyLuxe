商家端主页重画

设计图 v2 · 2026-09-03 · 图=合同 · 覆盖:小程序商家端首页(老板视角 / 员工视角)· 网页后台首页 · 前台全屏大屏态 · 并入并替代「老板主页业绩大屏 v1」

v1 差的那一点意思,我认为是这个:v1 只是「一块好看的数字牌」。店主 08-10 原话是「主页要有实时订单量的数字化体现」——大数字讲的是结果,主页还得讲此刻。所以 v2 在大数字下面加了两样只有美业店才有的东西:「此刻」脉搏行(在做几个、待到店几个、下一位几点谁做什么,绿点在跳)和「店里的一天」时间轴(营业时段一根横条,做完的、正在做的、还没来的一眼看全,一根绿线标着现在)。再加三样让它有分量:数字滚动到位的动效、本年维度、以及一个前台全屏态——把手机横过来或放在前台 iPad 上,它就是店里的大屏。

每一块的规矩
  1. 大屏(见 §四口径):四个维度 今日/本周/本月/本年;折线随维度 7 天 / 7 周 / 7 月 / 12 月。切换维度、轮播换指标时,数字从当前值滚动到新值(600ms,尊重系统「减少动态效果」则直接跳)。
  2. 此刻行:三个数来自今日台面同一状态机;「下一位」= 最近一个未到店的预约(时间 · 顾客 · 项目),没有则写「今天没有待到店的了」。绿点常亮不闪;数据每次进入首页/下拉时取,不轮询。
  3. 时间轴:横条 = 门店今日营业时段(取自营业时间设置;休息日整条灰并写「今日休息」);块 = 预约,按状态三色:做完实色、在做金色、未到虚框;多技师重叠的块叠半高;绿线 = 现在。点任意位置 → 跳台面对应时段。
  4. 今日要处理:一张清单,不是五张卡。来源固定五项:客服待人工 / 待报价 / 待写小记 / 调休申请 / 昨日日结待确认;数为 0 的行不出现,全为 0 则整块换一句「今天没有要处理的」。红条 = 顾客在等的两项。点行 → 跳对应页。
  5. 今日预约:只列此刻之后的前 3 条 + 「看全部」;过去的在台面看。
  6. AI 今日一句:现有每日总结,只保留一段两三句、带生成时间;没生成写「今天的总结还没生成」并可点「现在生成」。
  7. 快捷:八格固定顺序,不可配置(配置是以后的事)。
  8. 不再单独出现的旧块:「我的今日台面」卡并入此刻行+时间轴;「待办小记」并入今日要处理;「客服工作台」并入今日要处理;打卡/排班移到员工视角与「我的」页。

指标算什么锚在哪(不许另写一套)对比
营业收入
默认第一个		当期服务收入(现付 + 耗卡)+ 产品销售;红字冲销当期冲减(N-5)今日=日结页/财务页实时同一函数;已日结日=daily_closes.revenue_cents 快照。大屏今日营收 === 日结页今日营收比昨日 / 上周同期至今 / 上月同期至今 / 去年同期至今
现金业绩当期真进钱:pay_channel ≠ stored_value 的收入(现付服务、产品、充值、购卡)− 退款/冲销账本同表同过滤;充值/购卡计入,耗卡不计同上

新增持卡当期首次开卡顾客数(储值首充或首买次卡),按顾客去重首条充值/首张次卡落在当期绝对数

Code 动手前先现测答两问:①充值/购卡收款在账本里现在记的是哪个 category/pay_channel;②次卡消耗记在哪张表、有没有能落到「当期」的时间戳。答不上的那一格不上,不许 0 顶。

七、验收判据(锚字段与身份,不锚文案;每条先造病验红)

  1. 同口径:大屏 revenue.value === 日结页实时营收 === 财务页当期营收(同一夹具三处比对)。
  2. 已日结日 === daily_closes.revenue_cents 快照。
  3. metrics 恒五项、顺序固定;period=year 的 spark 恒 12 项。
  4. prev=0 → deltaPct === null,页面「上期 0」节点存在、无 ∞/NaN。
  5. 此刻行三数 === 今日台面同一时刻的三数(同源函数);「下一位」= 台面里最近一个未到店预约。
  6. 时间轴块数 === 今日预约数(按单);休息日 day.closed=true 时无块。
  7. 今日要处理:为 0 的项无节点;全 0 时真话块存在。
  8. 员工身份响应体不含店级 metrics;老板身份含。
  9. 币种随店;财务锁 locked 时不下发 value 且遮掩节点存在;全屏态默认无现金/新增持卡节点。
  10. 两端同源:同一 payload 两端五数字文本一致。
  11. 三态 + 休息日态各自真话节点存在且互斥;截图:老板/员工 × 三态 + 四维度 + 全屏 + 休息日,每张附 DOM 证据。

八、明确不做

不做图表页、不做导出、不做自定义指标或可配置快捷、不做多店汇总、不做首页轮询(全屏态除外)。顾客端首页另一张图。
