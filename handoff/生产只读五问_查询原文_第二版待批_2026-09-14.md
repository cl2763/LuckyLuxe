## 二、怎么跑(第 0 条 + 五条,全部 `SELECT`)

```
railway ssh
  sqlite3 -readonly /app/apps/api/local-data/lucky-luxe.sqlite
```

- **`-readonly` 走引擎层**:该模式下 `INSERT/UPDATE/DELETE/CREATE/ATTACH` 由引擎拒绝并报错。
- 不用 `.dump` / `.backup` / `.output`(会落文件);**零 `CREATE TEMP` · 零 `ATTACH` · 零 `PRAGMA` 写入 · 零 append**。
- 🔴 **`-readonly` 打不开(WAL/`-shm`)→ 停下来问。** 不去掉 `-readonly`,不改 journal 模式,不创建任何文件。
- 🔴 **没有 `sqlite3` → 停下来问**,不往生产上装东西。
- **六条全部 `GROUP BY tenant_id` 的聚合,一个手机号都不取**(顾客 PII 不出库)。

### 问 1 · 同号多条 —— **三档并排**

```sql
WITH n AS (
  SELECT tenant_id, TRIM(phone) AS lit,
         REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(TRIM(phone),' ',''),'-',''),'(',''),')',''),'+','') AS dig
  FROM users WHERE phone IS NOT NULL AND TRIM(phone) <> '')
SELECT t.tenant_id, t.有号档案数,
  (SELECT COUNT(*) FROM (SELECT lit FROM n WHERE n.tenant_id = t.tenant_id GROUP BY lit HAVING COUNT(*) > 1))                        AS 档1_字面,
  (SELECT COUNT(*) FROM (SELECT dig FROM n WHERE n.tenant_id = t.tenant_id GROUP BY dig HAVING COUNT(*) > 1))                        AS 档2_去符号,
  (SELECT COUNT(*) FROM (SELECT SUBSTR(dig, -10) AS t10 FROM n WHERE n.tenant_id = t.tenant_id GROUP BY t10 HAVING COUNT(*) > 1))    AS 档3_后十位
FROM (SELECT tenant_id, COUNT(*) AS 有号档案数 FROM n GROUP BY tenant_id) t
ORDER BY 档3_后十位 DESC, t.tenant_id;
```

### 问 2 · 没有手机号 —— NULL 归到「非导入或未知」

```sql
SELECT tenant_id,
    COUNT(*) AS 顾客总数,
    SUM(CASE WHEN phone IS NULL OR TRIM(phone) = '' THEN 1 ELSE 0 END) AS 没有手机号,
    SUM(CASE WHEN (phone IS NULL OR TRIM(phone) = '') AND is_migrated = 1 THEN 1 ELSE 0 END) AS 没号_导入,
    SUM(CASE WHEN (phone IS NULL OR TRIM(phone) = '') AND (is_migrated IS NULL OR is_migrated <> 1) THEN 1 ELSE 0 END) AS 没号_非导入或未知,
    SUM(CASE WHEN is_migrated IS NULL THEN 1 ELSE 0 END) AS is_migrated为空的行数,
    SUM(CASE WHEN wechat_open_id IS NOT NULL AND wechat_open_id <> '' THEN 1 ELSE 0 END) AS 已绑微信
FROM users GROUP BY tenant_id ORDER BY 没有手机号 DESC;
```

### 问 4 · 有余额的人(含**余额为负**两列,只报)

```sql
WITH b AS (
  SELECT u.id, u.tenant_id, u.phone,
    REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(TRIM(u.phone),' ',''),'-',''),'(',''),')',''),'+','') AS dig,
    (SELECT COALESCE(SUM(s.amount_cents),0) FROM stored_value_transactions s
      WHERE s.user_id = u.id AND s.tenant_id = u.tenant_id) AS bal
  FROM users u)
SELECT b.tenant_id,
  SUM(CASE WHEN b.bal > 0 THEN 1 ELSE 0 END)                                                    AS 有余额的顾客数,
  SUM(CASE WHEN b.bal > 0 THEN b.bal ELSE 0 END)                                                AS 余额合计分,
  SUM(CASE WHEN b.bal > 0 AND (b.phone IS NULL OR TRIM(b.phone) = '') THEN 1 ELSE 0 END)         AS 有余额_没手机号,
  SUM(CASE WHEN b.bal > 0 AND b.dig <> '' AND (SELECT COUNT(*) FROM b b2
        WHERE b2.tenant_id = b.tenant_id AND SUBSTR(b2.dig,-10) = SUBSTR(b.dig,-10)) > 1 THEN 1 ELSE 0 END) AS 有余额_同号多条_后十位档,
  SUM(CASE WHEN b.bal < 0 THEN 1 ELSE 0 END)                                                    AS 余额为负的顾客数,
  SUM(CASE WHEN b.bal < 0 THEN b.bal ELSE 0 END)                                                AS 负余额合计分
FROM b GROUP BY b.tenant_id ORDER BY 有余额的顾客数 DESC;
```

### 问 5 · 有卡包 / 有积分的人 —— **积分口径已改对**

```sql
WITH c AS (
  SELECT u.id, u.tenant_id, u.phone,
    REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(TRIM(u.phone),' ',''),'-',''),'(',''),')',''),'+','') AS dig,
    (SELECT COUNT(*) FROM coupon_grants g
      WHERE g.user_id = u.id AND g.tenant_id = u.tenant_id AND g.status = 'active') AS 券数,
    -- 🔴 积分 = 已签署结算单推出的赚分 + 台账行(只查台账会把「挣过但没兑换过」的老顾客数成 0)
    (SELECT COALESCE(SUM(st.subtotal_cents/100),0) FROM settlements st
      WHERE st.user_id = u.id AND st.tenant_id = u.tenant_id AND st.status = 'signed')
    + (SELECT COALESCE(SUM(p.amount),0) FROM points_transactions p
      WHERE p.user_id = u.id AND p.tenant_id = u.tenant_id) AS 积分
  FROM users u)
SELECT c.tenant_id,
  SUM(CASE WHEN c.券数 > 0 THEN 1 ELSE 0 END)                                                   AS 有卡包的顾客数,
  SUM(CASE WHEN c.券数 > 0 AND (c.phone IS NULL OR TRIM(c.phone) = '') THEN 1 ELSE 0 END)        AS 卡包_没手机号,
  SUM(CASE WHEN c.券数 > 0 AND c.dig <> '' AND (SELECT COUNT(*) FROM c c2
        WHERE c2.tenant_id = c.tenant_id AND SUBSTR(c2.dig,-10) = SUBSTR(c.dig,-10)) > 1 THEN 1 ELSE 0 END) AS 卡包_同号多条_后十位档,
  SUM(CASE WHEN c.积分 > 0 THEN 1 ELSE 0 END)                                                   AS 有积分的顾客数,
  SUM(CASE WHEN c.积分 > 0 AND (c.phone IS NULL OR TRIM(c.phone) = '') THEN 1 ELSE 0 END)        AS 积分_没手机号,
  SUM(CASE WHEN c.积分 > 0 AND c.dig <> '' AND (SELECT COUNT(*) FROM c c2
        WHERE c2.tenant_id = c.tenant_id AND SUBSTR(c2.dig,-10) = SUBSTR(c.dig,-10)) > 1 THEN 1 ELSE 0 END) AS 积分_同号多条_后十位档
FROM c GROUP BY c.tenant_id ORDER BY 有积分的顾客数 DESC;
```
