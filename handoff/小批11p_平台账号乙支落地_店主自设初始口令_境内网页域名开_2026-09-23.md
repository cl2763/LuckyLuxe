## §二 乙支怎么做(和 `WECHAT_MINI_TOKEN_SECRET` 同族)

### 环境变量两把(**店主亲手在 Railway 设,Code / Cowork 不看不印不猜**)

| 变量 | 值 | 谁设 |
|---|---|---|
| `PLATFORM_ADMIN_BOOTSTRAP` | `1` | 店主 |
| `PLATFORM_ADMIN_INITIAL_PASSWORD` | 店主自己生成的一串(建议 ≥ 16 位随机) | 店主 |

### 代码改动(`platform-auth.mjs`,只动 `bootstrapAndReport`)

- `BOOTSTRAP=1` **且** `INITIAL_PASSWORD` 非空 ⇒ 建 `platform-admin`,`password_hash = hash(username, INITIAL_PASSWORD)`,`must_change_password = 1`
- `BOOTSTRAP=1` 但 `INITIAL_PASSWORD` 空 ⇒ **不建**,日志一句「缺初始口令,未建」;**不许回落成随机口令**(那就回到 D203 之前)
- 账号已存在 ⇒ **一个字不动**(幂等,重启一百次不换密码)
- 🔴 日志里**只许出现「建了 / 没建 / 为什么没建」**,值、长度、前缀、哈希一律不出现

### 「以后忘了密码怎么办」—— 同一条路加一把

- `PLATFORM_ADMIN_RESET=1` + `PLATFORM_ADMIN_INITIAL_PASSWORD=新值` ⇒ 对**已存在**的 `platform-admin` 重写哈希、`must_change_password=1`、**作废它所有会话**;完成后日志一句「已重置」
- 🔴 `RESET=1` 但缺新口令 ⇒ 不动;`RESET` 每次生效后店主应把它删掉(代码层面幂等:同一值不会重复生效 —— 记 `platform_accounts.reset_marker = sha256(值)`,同值第二次启动不再重置)

### 判据(进主档 + 门关档 + 推前清单,**造病四条**)

1. `BOOTSTRAP=1` 无口令 ⇒ 不建、不崩
2. 有口令 ⇒ 建成;用该口令 `POST /platform/auth/login` 200 且 `mustChangePassword=true`;**改密后旧口令 401**
3. 账号已在 + 再启动 ⇒ 哈希不变
4. 🔴 **启动全部输出 grep 口令原文 = 0 命中,grep 其 sha256 前 8 位 = 0 命中**
5. `RESET` 同值两次 ⇒ 第二次不动;`RESET` 后旧会话 401

### 店主要做的(顺序,**Code 推上去、Railway 重启完之后**)

1. Railway → Variables:加 `PLATFORM_ADMIN_BOOTSTRAP=1` 与 `PLATFORM_ADMIN_INITIAL_PASSWORD=<你生成的>`
2. 等重启 → 打开 `/platform` → 用户名 `platform-admin` + 那串 → **首登强制改密,改成你自己的**
3. 改完把 `PLATFORM_ADMIN_INITIAL_PASSWORD` **从 Railway 删掉**(留着不危险,但没必要留)
4. 新密码**自己记进本机凭据文件 D149 节**;**不发给 Code,不发给 Cowork**
