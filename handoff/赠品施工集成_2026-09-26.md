## 数据合同

`giftItems: [{ name, quantity, unitValueCents }]`，最多 20 行，名称 trim 后 1–80 字，数量整数 1–999，价值为整数分 0–100000000。显式 null、负数、小数数量、空名、异常数组后端拒绝，不静默删行或变零。
实物价值仅展示；不并入现金、赠额、余额、积分或提成。没有领取状态，固定文字说明「物品领取请联系门店，此清单不代表已领取」。

## 已实施文件域

- `apps/api/gifts.mjs`：`normalizeGiftItems(value, apiError)`、`readGiftItems(row)`、`ensureGiftSchema(db)`、`giftSnapshotOfPackage(row)`。
- `apps/api/stored-value.mjs`：factory 兼容补 schema；`insertStoredValueTransaction` 增可选 `giftItems=[]` 参数，在充值 INSERT 同刻写入 JSON。非充值流水清单空，不改资金数，不 UPDATE 旧流水。
- `apps/web/gift-editor.js`：`window.GiftEditor.mount(container, items, currencyPrefix)`；返回 `{read(), element}`。read 返回合法 giftItems，非法抛可读错误；最多 20 行，含添加、删除、长名、窄屏样式。
- 双端顾客商城、储值流水/回执展示；网页签署 `apps/web/sign.html` 展示充值赠品（mini 签署复用此 web-view，并非另有实现）。
- 小程序 merchant/package-edit 多行录入及 owner guard、CAD 硬编码改为门店币种，修正负售价被剥负号变正值的旧问题。
- 双端 account-adjust 选择套餐时传 `packageId`，选中展示赠品；金额/赠额编辑走原有解除套餐状态逻辑。手动充值不提交 giftItems。
- 顺查小程序储值页 `Math.round(cents/100)` 抹掉分的显示问题已修正，金额统一保留两位小数；相关固定浅色底接现有主题。

## Root 接入清单（请按语义搜索，行号会随并行改动变化）

### admin UI

1. admin.html 加 `/web/gift-editor.js`，在 admin.js 前加载。
2. 现有 `openFormModal` 增可选 mount 扩展，例如 `mountContent(overlay)` 与 readExtra。mount 在 form append 后执行；readExtra 的结果并入 readValues。保存失败保留所有行；保存中禁止重入。
3. savePackage 充值型使用 `GiftEditor.mount(host, existing?.giftItems||[], currencyPrefix)`。host 插 `.action-row` 前；`body.giftItems=editor.read()`。次卡不挂赠品编辑。

### API local-server

1. schema 创建之后调用 `ensureGiftSchema(db)`（factory 已兼容补列，但显式启动点更清楚）。
2. 套餐 POST/PATCH：`giftItems` 用 `normalizeGiftItems`，PATCH 未提供保留旧值，提供 [] 清空。写 `membership_packages.gift_items_json`，且 PATCH 的合法金额校验不得绕过 POST。非充值类型不可保留实物赠品。
3. `serializeMembershipPackage`、`/my/mall` item、`/admin/recharge-packages` 加 `giftItems: readGiftItems(row)`，仅 recharge 类型返回。
4. **直接充值** `/admin/stored-value/recharge`：用户须限定 currentTenantId；packageId 选择 active、本租户、kind recharge；金额/bonus/gifts 来后端所选套餐。客户端 giftItems 不可信、不读取。无 packageId 时清单 []，保持既有纯手动金额口径。充值 INSERT 传 `giftItems`，bonus INSERT 不传。
5. **随单充值** `buildSettlementPreview` 读取 rpkg 时 `giftSnapshotOfPackage(rpkg)`，放到 `scRecharge.giftItems`，其后保存到 recharge_json；签署执行时给 recharge INSERT 传 `scRecharge.giftItems || []`。不得签署时重读可能已修改的套餐。
6. `/my/stored-value` SQL SELECT 加 `gift_items_json`；txns、pendingConfirm 均 `giftItems: readGiftItems(t)`。
7. `serializeSettlement` recharge 返回对象目前手工重建（`amountCents:r.amountCents`处），需加 `giftItems: normalizeGiftItems(r.giftItems || [])`。签署网页读取这个字段。
8. 快照 SVG `if(s.recharge && s.recharge.lines)` 块追加赠品名称/数量/单件价值及未领取说明，使用 escapeXml。单件价值按门店币种，长名换行，不能挤掉签名区。
